# KIS 오픈API 연동

## 철칙

1. **문서가 유일한 스펙이다.** 엔드포인트·TR ID·필드명·필드 순서를 기억이나 추측으로 쓰지 말 것. 반드시 `docs/koreainvestment/`의 해당 `.md`를 읽고 그대로 옮긴다. 목차: [docs/koreainvestment/README.md](../../../docs/koreainvestment/README.md) — 문서별 API명·실전/모의 TR ID 표.
2. **TR ID가 비어 있으면 주문이 나가면 안 된다.** 주문 계열 함수는 TR ID 미설정 시 API 호출 전에 에러로 차단하는 안전장치를 반드시 유지한다.
3. **실전/모의는 도메인·TR ID가 모두 다르다.** 실전 `openapi.koreainvestment.com:9443` / 모의 `openapivts.koreainvestment.com:29443`. TR ID는 실전 `T…`/`C…`/`H…`, 모의 `V…` — 문서 표에서 짝을 맞춰 가져온다.
4. **실시간(WebSocket) 응답의 필드 순서 = 파싱 스펙.** 구분자(`^`)로 나뉜 값 배열이라 순서가 틀리면 에러 없이 조용히 잘못된 가격이 계산된다. 필드 인덱스는 문서의 인덱스 열을 그대로 쓰고, 원본 필드 덤프 모드(`RAW_FIELD_DEBUG` 류)를 구현해 실계좌 투입 전 실데이터와 대조한다.

## 함정 목록 (문서·실측으로 검증된 것)

- **웹소켓 "시세"는 모의투자 미지원** — 시세 구독은 항상 실전 도메인으로 우회한다 (financial 프로젝트 실측, 2026-07). 단, **체결"통보"(H0GSCNI0)는 예외로 모의 TR(H0GSCNI9)이 존재**한다.
- **분봉은 지수/종목이 별개 API** — 종목 분봉은 `HHDFS76950200`(분봉조회.md), 지수 분봉은 `FHKST03030200`(이 저장소에 문서 없음). 혼용 금지.
- **실시간체결통보의 `tr_key`는 계좌번호가 아니라 HTSID**(HTS 로그인 ID). 체결단가는 국가별 소수점 생략 자릿수(미국 4, 일본 1, 중국·홍콩 3, 베트남 0)를 복원해야 한다.
- **미국 모의 매도 TR은 `VTTT1001U`** (공식 GitHub 검증). 문서 오기 이력이 있으니 주문.md 표 기준으로 재확인.
- **순위 API 6종(거래량순위·거래량급증·가격급등락·거래증가율·거래회전율·매수체결강도)은 전부 모의 미지원.** `EXCD`는 NYS/NAS/AMS 외 아시아 거래소 포함.
- **`NDAY` 파라미터 단위가 문서마다 다르다** — 매수체결강도상위만 "분" 단위, 나머지 순위는 "일" 단위.
- **실시간호가(HDFSASP0) tr_key는 세션별로 다르다** — 야간거래(=한국 밤, 미국 정규장) 무료 = **D**+시장+티커, 주간거래 = R+BAQ/BAY/BAA, 아시아 유료 = R+시장+티커. 필드명이 "R거래소명종목코드"라 R로 오독하기 쉬운데 **정규장은 D가 정답**(공식 샘플 asking_price("1","DNASAAPL") 일치. R을 정규장에 쓰면 "mci send failed" 거절 — 실측 2026-07-31).
- **주간거래(R+BAQ/BAY/BAA) 키는 주간거래 대상 종목에만 통한다** — 대상이 아닌 종목(순위 리스트의 소형·급등주에 흔함)은 정확한 키여도 "mci send failed"로 거절된다(실측 2026-08-28, KST 15시 물타기 모드 전 종목 실패 제보). 이 메시지는 접속키(approval_key) 문제가 아니라 시세서버(MCI)의 tr_key 거절이다 — 접속키 재발급으로 풀리지 않는다. 진단 문구엔 항상 거절된 tr_key를 같이 적는다.
- **실시간호가 응답 필드 레이아웃이 문서와 공식 샘플이 다르다** — 포탈 문서 표는 맨 앞에 RSYM, 공식 샘플 columns는 RSYM 없이 symb부터. 파싱은 첫 필드의 RSYM 패턴(^[DR]+시장 3자리)을 자동 감지해 오프셋을 정하는 관용 방식 사용(kis/realtimePrice.ts parseOverseasRealtimeQuote 참조).
- **토큰은 24h 유효·6h 갱신 주기** — 6h 이내 재호출 시 기존 토큰이 반환된다. 매 호출 발급 금지, 만료시각 기준 캐시 필수 (잦은 발급 요청은 서버가 제어함).
- 원문 오탈자 주의: balance의 `frcr_evlu_amt2` 필드명 중복(output1·output2 의미 다름), 주문의 `SLL_TYPE` 설명 "제거 : 매수" 표기 등 — README "원문 특이사항" 절 참조.

## 작업 절차

1. 구현할 API를 [README.md](../../../docs/koreainvestment/README.md) 표에서 찾는다. 없으면 **구현하지 말고** 원문 확보를 사용자에게 요청한다 (README "미확보 원문" 체크리스트 참조).
2. 해당 `.md` 문서를 읽고 기본 정보(Method/URL/TR ID)·요청 헤더/바디·응답 바디를 코드에 옮긴다. `.md` 상단에 ⚠️ 편집자 주가 있으면 그 지시를 우선한다.
3. 응답 필드는 문서에 있는 것만 파싱하고, Length·Type 오기가 의심되면 임의 보정하지 말고 주석으로 남긴다.
4. 새로 확보한 원문 `.txt`가 추가되면 같은 이름의 `.md` 변환본과 README 표 행도 함께 갱신한다.
