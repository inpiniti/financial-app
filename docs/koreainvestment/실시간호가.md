# [해외주식] 실시간시세 — 해외주식 실시간호가[실시간-021]

> 원문: 실시간호가.txt (KIS API 포탈 복사본) — 변환 시 필드 추가/삭제 없음. 원문의 중복 표기는 아래 "특이사항"에 기록하되 표 자체는 원문 순서를 보존.

## 개요

해외주식 실시간호가 API로 **미국 실시간 10호가(매수/매도)가 무료** 제공된다(미국은 유료시세 제공 X, 나스닥 마켓센터 호가·잔량, 0분지연).

아시아(홍콩·베트남·중국·일본)는 HTS [7781] 유료 신청 시 이 API로 유료시세 수신 가능. 아시아 무료시세는 지연호가(아시아) HDFSASP1 사용. 미국주간거래(10:00~16:00)도 이 API로 조회 가능.

### Body

| Element | 한글명 | Type | Required | Length | Description |
|---|---|---|---|---|---|
| tr_id | 거래ID | String | Y | 7 | HDFSASP0 |
| tr_key | R거래소명종목코드 | String | Y | 6 | **미국 야간거래(무료)**: `D`+시장구분(3)+종목코드 예) DNASAAPL<br>**미국 주간거래**: `R`+시장구분(3)+종목코드, 시장구분 BAY(뉴욕)/BAQ(나스닥)/BAA(아멕스) 예) RBAQAAPL<br>**아시아 유료시세**: `R`+시장구분(3)+종목코드 예) RHKS00003<br>[시장구분] NYS 뉴욕, NAS 나스닥, AMS 아멕스, TSE 도쿄, HKS 홍콩, SHS 상해, SZS 심천, HSX 호치민, HNX 하노이 |

> ⚠️ tr_key 접두 판단(구현 반영): 원문 요청 표는 `D…` 예시(DNASAAPL)를 들지만, 이는 실시간지연체결가(HDFSCNT0)와 공용 서술의 잔재로 보인다. 응답 필드 `RSYM`(실시간종목코드)·문서 제목의 "R거래소명종목코드" 표기에 맞춰 **본 구현은 호가 구독에 `R`+시장구분+종목코드(예: RNASAAPL)를 사용**한다(체결가 구독은 기존대로 `D…`). 실계좌 리허설에서 RAW 덤프로 재검증할 것.

## 특이사항 (원문 보존 — 임의 보정 금지)

- **3호가 그룹(PBID3~DASK3) 6필드가 원문에 두 번 연속 표기**되어 있다(요청·응답 Data Class 양쪽 모두). 포탈 복사 잔재로 추정된다. 그대로 인덱스를 매기면 4호가 이후가 6칸씩 밀리므로, **4호가 이상 인덱스는 실계좌 RAW 덤프로 재확정 전까지 신뢰하지 말 것.**
- **우리 구현은 1호가(PBID1=11, PASK1=12, VBID1=13, VASK1=14)만 소비**한다. 1호가는 중복 표기 지점(23~28 이후) 앞이라 인덱스가 정확하다. 따라서 `kis/realtimePrice.ts`의 호가 파서는 **총 필드 개수를 검사하지 않고**(중복으로 불확정) 앞쪽 고정 인덱스만 읽으며, 1호가까지 담기는 최소 15필드 미만일 때만 throw한다.
- 포탈 복사 잔재로 모든 표 캡션이 "주식주문(현금[V1_국내주식-001]) …"으로 잘못 찍혀 있음 — 실제 API와 무관한 템플릿 텍스트.
- 응답 Data Class(Python) 예시의 `RSYM` 타입이 `ResponseBodyRSYM`(Object)으로 되어 있으나 실제 push는 String(`^` 구분) — 표의 Description 주석대로 String 취지.
