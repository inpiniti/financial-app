## 원문 자체의 특이사항 (변환 시 수정하지 않고 보존)

- 포탈 복사 잔재로 모든 표 캡션이 "주식주문(현금[V1_국내주식-001]) …"으로 잘못 찍혀 있음 — 실제 API와 무관한 템플릿 텍스트.
- balance: `frcr_evlu_amt2` 필드명이 output1(외화평가금액2)·output2(출금가능원화금액)에 중복. `thdt_buy_ccld_frcr_amt`는 Type Object로 표기됐으나 실제 String 취지의 주석 있음.
- 주문: `SLL_TYPE` 설명에 "제거 : 매수" 표기(원문 그대로). 매수가능금액조회: appsecret 설명이 "appkey"로 오기.
- 실시간체결내역통보: `tr_id` Length 7로 표기됐으나 값 HDFFF2C0은 8자.
- 순위 7종: `NDAY` 파라미터가 거래증가율·거래회전율·상승율하락율 등에서는 "N일전(0=당일~9=1년)"인데 **매수체결강도상위만 "N분전(0=1분전~9=120분전)"** — 같은 이름·다른 단위이므로 코드에서 문서별로 확인 필수. 또 `GUBN`은 가격급등락(급락/급등)과 상승율하락율(하락율/상승율)이 값은 같고 의미만 다르며, 시간창은 각각 MINX(분)·NDAY(일)로 갈린다. 거래증가율·거래회전율의 `symb` Length가 1로 표기(오타로 보임, 타 문서는 16).
