# [해외주식] 실시간시세 — 해외주식 지연호가(아시아)[실시간-008]

> 원문: 지연호가.txt (KIS API 포탈 복사본) — 변환 시 필드 추가/삭제 없음

> ⚠️ 편집자 주: 이 문서(HDFSASP1)는 **아시아 거래소 전용**이다(도쿄/홍콩/상해/심천/호치민/하노이). **미국 종목 호가는 지원하지 않는다.** 미국 호가가 필요하면 REST 해외주식 현재가 호가 또는 WS 실시간호가 HDFSASP0(원문 미확보, 유료시세)를 별도로 사용해야 한다.

## 개요

해외주식 지연호가(아시아)의 경우 아시아 무료시세(지연호가)가 제공됩니다.

HTS(efriend Plus) [7781] 시세신청(실시간) 화면에서 유료 서비스 신청 시,
"해외주식 실시간호가 HDFSASP0" 을 이용하여 아시아국가 유료시세(실시간호가)를 받아보실 수 있습니다. (24.11.29 반영)

※ 지연시세 지연시간 : 홍콩, 베트남, 중국, 일본 - 15분지연

## 원문 자체의 특이사항 (변환 시 수정하지 않고 보존)

- 포탈 복사 잔재로 표 캡션이 "주식주문(현금[V1_국내주식-001]) …"으로 잘못 찍혀 있음 — 실제 API와 무관한 템플릿 텍스트.
- 호가 필드가 PBID1/PASK1(1호가) 단 하나만 제공됨 — 국내주식 호가류처럼 다단계(2~10호가)가 아니라 **1호가 전용**(원문 그대로).
- tr_key Length가 6으로 표기됐으나 예시 `DHKS00003`은 9자(D+HKS+00003) — 원문 그대로 보존.
- 아시아 전용 API로, tr_key 시장구분에 미국(NYS/NAS/AMS)이 존재하지 않음 — 미국 호가는 이 API로 조회 불가(편집자 주 참고).
