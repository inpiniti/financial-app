# 주문 (Order) 도메인

> **주문 도메인**은 실시간 MA5 단일 전략에 맞추어 **신규 진입 매수(현재가 지정가)**, **체결 즉시 +3% 익절 매도 선등록**, **목표가 초과 시 상향 추격(Chase Up)**, **물타기 추가 매수**, 그리고 **실시간 체결통보(Fill Event) 수신 및 브로커 상태 동기화**를 전담하는 핵심 거래 실행 도메인입니다.

---

## 1. DDD 모델

### 엔티티 (Entity)
- **`Order`**: 주문의 전체 라이프사이클을 추적하는 핵심 엔티티.
  - 식별자: `orderRef`(내부 식별자), `odno`(KIS 원주문번호)
  - 속성: `symbol`, `side` (`buy` / `sell`), `orderQty`, `orderPrice`, `filledQty`, `avgFilledPrice`
  - 상태 머신 (`OrderStatus`):
    - `SUBMITTED`: 발주 요청 전송
    - `PENDING`: 브로커 접수 완료(원주문번호 odno 수신), 체결 대기
    - `AMENDING`: 목표가 초과 상향 추격 정정 요청 중
    - `PARTIALLY_FILLED`: 일부 체결 (잔량 취소 시에도 체결 수량 절대 보존)
    - `FILLED`: 전량 체결 완료
    - `CANCELLED`: 미체결 취소 (타임아웃 또는 평단 갱신에 따른 매도 주문 교체)
    - `FAULT`: 주문 거부 또는 브로커 장애

### 값 객체 (Value Object)
- **`OrderRequest`**: 신규 발주 요청 규격 (`symbol`, `side`, `qty`, `price`).
- **`FillEvent` (Domain Event)**: 체결 수신 이벤트 (`odno`, `symbol`, `side`, `fillQty`, `fillPrice`, `isFullFill`, `filledAt`).
- **`CancelResult`**: 취소 확정 상태 (`confirmed` 미체결 취소 성공, `rejected` 이미 체결되어 취소 불가).

### 애그리게잇 (Aggregate)
- **`OrderExecutionAggregate` (Root: `OrderPortAdapter` & `ExecutionPort`)**:
  - 발주된 주문과 브로커(KIS) 간의 데이터 일관성을 책임집니다.
  - **취소-체결 레이스 방어**: 취소가 거절(`rejected`)된 경우 즉시 실패로 단정하지 않고 실시간 체결통보 및 체결내역 폴링 결과로 최종 상태를 확정합니다.
  - **호가 절사 엄격 준수**: 미국주식 호가 단위(`roundOverseasOrderPrice`)를 발주 전에 엄격히 강제합니다.

### 도메인 서비스 (Domain Service)
- **`ChaseUpService`**: 체결 선등록 매도 주문 상태에서 현재가가 목표가(평단×1.03)를 초과하여 추가 상승할 때만 현재가로 상향 정정 주문을 발행합니다 (하향 양보 없음).
- **`FillStreamRouter`**: KIS 웹소켓 실시간 체결통보 및 REST 체결 폴링 스트림을 파싱하여 해당 `Order`로 라우팅하고 `OrderFilledEvent`를 발행합니다.

## 2. 실시간 MA5 전략 주문 라이프사이클 3원칙

현행 단일 전략(`realtimeMa5`)의 주문 실행은 다음 3단계 파이프라인을 엄격히 따릅니다:

1. **신규 진입 매수 주문 (Entry Buy)**:
   - **발주가**: 5선 상향 돌파 신호 시점의 **현재가 지정가** (불필요한 호가 슬리피지 방지).
   - **미체결 처리**: 설정된 제한 시간(`buyCancelAfterMs`) 동안 미체결 시 취소하고 슬롯을 반납하여 다음 신호를 대기합니다.
2. **익절 선등록 매도 주문 (Pre-registered Take-Profit Sell)**:
   - **발주가**: 매수 체결 즉시 **평단가 × 1.03 (+3%) 지정가**로 브로커에 선등록합니다.
   - **상향 추격 (Chase Up)**: 현재가가 목표가를 뚫고 더 치솟을 때만 현재가를 따라 상향 정정하며, 하락장에서는 가격을 절대 하향 양보하지 않습니다.
3. **물타기 추가 매수 및 매도 교체 (Averaging Down & Re-bracket)**:
   - **추가 매수**: 평단가 대비 -3% 이하에서 5선 돌파 시 **현재가 지정가**로 발주합니다.
   - **매도 교체**: 추가 매수 체결 즉시 기존 선등록 매도 주문을 취소하고, **새 평단가 × 1.03 기준의 새 매도 주문으로 즉시 교체 등록**합니다.

---

## 3. 도메인 불변식 (Invariants)

1. **리프라이스 하향 양보 금지**:
   - 매도 주문은 목표가(+3%) 이상의 상향 추격만 허용되며, 시간이 경과하더라도 가격을 아래로 내리는 시간 에스컬레이션(사실상의 시장가 손절)을 원천 금지합니다.
2. **부분 체결 수량 절대 보존**:
   - 부분 체결(`PARTIALLY_FILLED`) 상태에서 취소가 발생하더라도 체결된 수량은 절대 유실되지 않고 포지션 평단 및 수량에 정확히 계상됩니다.
3. **포지션 수량 일치 불변식**:
   - 보유 수량(`qty`)과 브로커에 등록된 선등록 매도 주문 수량은 항상 일치해야 합니다.
4. **취소-체결 경합 방어**:
   - 브로커 취소 요청 거절 시 "이미 체결 완료" 여부를 실시간 통보 및 체결내역 폴링을 통해 최종 확정합니다.
