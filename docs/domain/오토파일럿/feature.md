# 오토파일럿 — 기능 명세 (Feature)

## 1. 주요 유스케이스

### UC-AP-01: 오토파일럿 엔진 시작 / 정지
- **액터**: 사용자
- **사전조건**: 계좌 정보(CANO, 키) 및 기본 전략 설정 완료
- **기본 흐름**:
  1. 사용자가 메인 화면에서 오토파일럿 스위치를 활성화(`START`).
  2. 시스템은 현재 세션(프리/정규/애프터)을 확인하고 화면 꺼짐 방지(`keepAwake`) 활성화.
  3. 랭킹 상위 종목을 조회하여 감시 슬롯을 초기화하고 `SCANNING` 상태 진입.
- **예외 흐름**:
  - 장 마감 이후 시간이면 안내 토스트 출력 후 가동 차단.

### UC-AP-02: 자동 상태 전이 라이프사이클
- `SCANNING`: 틱 수신 중 전략(MA5 돌파) 매수 시그널 검사.
- `ENTERING`: 매수 주문 발주 후 체결 대기.
- `HOLDING`: 체결 완료 후 포지션 등록, 익절 매도 주문 선등록(+3%) 및 물타기 감시.
- `EXITING`: 익절 체결 또는 마감 타임아웃에 의한 전량 매도 진행.
- `FAULT`: 네트워크 단절, 잔고 불일치 등 예외 시 슬롯 격리 및 알림.

### UC-AP-03: 장 마감 일괄 청산 (19:55 ET 타임아웃)
- 미국 동부시간 19:55 도달 시 모든 활성 슬롯에 마감 청산 이벤트 발행.
- 미체결 매수 주문 즉시 취소, 보유 수량 전량 매도 실행 후 `IDLE` 복귀.

### UC-AP-04: 상세화면 수동 진입(매수) 및 청산(매도)
- **액터**: 사용자
- **사전조건**: 오토파일럿 엔진 구동 중 (또는 사용자 시작 승인)
- **기본 흐름 (매수 `buyNow`)**:
  1. 사용자가 상세화면에서 [매수] 버튼을 누르면 설정된 1회 진입금액(`startAmountUsd`) 또는 고정수량(`fixedQty`)으로 현재가 지정가 발주 실행.
  2. 주문이 `actives`에 등록되어 체결 시 포지션 관리자로 자동 인계되고, +3% 선등록 및 물타기 감시가 즉시 시작됨.
- **기본 흐름 (매도 `sellNow`)**:
  1. 사용자가 상세화면에서 [매도] 버튼을 누르면 보유 수량 전량에 대해 현재가 추격 매도 실행.
  2. 기존에 걸려있던 선등록 매도 주문은 취소되고 즉시 전량 매도로 교체됨.
  3. 체결 완료 시 사이클 정상 정산 및 거래 기록 생성.
- **예외 흐름**:
  - 이미 보유 중인 종목은 [매수] 버튼 비활성화 (중복 진입 차단).
  - 보유하지 않은 종목은 [매도] 버튼 비활성화.

### UC-AP-05: 트레이딩 진입 크기 기준 설정 (UI/UX 일체형 입력)
- **액터**: 사용자
- **사전조건**: 설정 화면(SettingsScreen) 진입
- **기본 흐름**:
  1. 진입 크기 기준은 `진입금액 기준(USD)`과 `수량 기준(주)` 중 하나를 선택(양자선택)하여 운용한다.
  2. 라디오 버튼과 단위 입력창(`[금액] USD`, `[수량] 주`)이 분리되지 않고 단일 행 카드/슬롯으로 일체화되어 제공된다.
  3. 특정 입력 필드를 터치하거나 포커스하면 해당 기준 모드가 자동으로 선택(활성화)된다.
  4. 선택되지 않은 모드의 입력 필드는 비활성(딤드) 처리되어 오입력을 방지하고 현재 적용 중인 기준을 명확히 전달한다.
  5. 저장 시 선택된 모드에 따라 유효성을 검증하며, 미선택 모드의 값은 보존하되 엔진 계산에는 선택된 기준만 투영된다.

### UC-AP-06: 트레이딩 리스트 아이템 및 인라인 가격 게이지 미니멀 렌더링
- **액터**: 사용자
- **사전조건**: 오토파일럿 트레이딩 화면 진입
- **기본 흐름**:
  1. 트레이딩 리스트 아이템 상단에서 중복 틱속도(`틱/분`) 및 원천 랭킹 배지를 제거하여 종목명과 현재가에 시각적 집중도를 부여한다.
  2. 인라인 가격 게이지(InlineGrid)는 텍스트 겹침 방지 및 직관적 시각화를 위해 최소/최대 레인지 트랙 상에서 다음 3대 지표를 기호로만 심플하게 표시하며, 상/하단 화살표 지시자는 트랙 선(Track Line) 표면에 빈 틈 없이 완전히 밀착(맞닿음)되어 표시된다:
     - 현재가: 트랙 상단에서 아래를 가리키며 트랙 윗면에 끝점이 맞닿는 검정색 역삼각형 기호(`▼`)
     - 평단가: 트랙 중앙을 관통하는 파란색 세로 바(`|`) (보유 종목에 한함)
     - 5선: 트랙 하단에서 위를 가리키며 트랙 아랫면에 끝점이 맞닿는 노란색 정삼각형 기호(`▲`)
  3. 현재가, 평단가, 5선에 대한 개별 텍스트 및 라벨은 생략하여 동일/인접 가격대에서의 텍스트 겹침을 원천 차단하고 컴팩트한 레이아웃을 제공한다.
  4. 게이지의 좌/우 양단에는 범위 척도로서 최소가(좌측) 및 최대가(우측)만 보조적으로 표시한다.
  5. 종목명 바로 아래에는 빈 공간 없이 슬롯 상태 배지(`SlotBadge`) 및 속도/기울기 라인이 즉시 수직으로 밀착(끌어올림)되어 배치된다.
  6. 트레이딩 리스트의 각 종목 사이에는 중간에 끊김 없이 화면 좌측 끝(0px)부터 우측 끝(100%)까지 완전하게 이어지는 풀폭 구분선(Full-width Divider)을 제공한다.
