# 오토파일럿 — 기능 명세 (Feature)

## 1. 주요 유스케이스

### UC-AP-01: 오토파일럿 엔진 시작 / 정지
- **액터**: 사용자
- **사전조건**: 계좌 정보(CANO, 키) 및 기본 전략 설정 완료
- **기본 흐름**:
  1. 사용자가 메인 화면에서 오토파일럿 스위치를 활성화(`START`).
  2. 시스템은 현재 세션(프리/정규/애프터)을 확인하고 화면 꺼짐 방지(`keepAwake`) 활성화.
  3. 랭킹 상위 종목을 조회하여 감시 슬롯을 초기화하고 `SCANNING` 상태 진입.
- **예외 흐름**:
  - 장 마감 이후 시간이면 안내 토스트 출력 후 가동 차단.

### UC-AP-02: 자동 상태 전이 라이프사이클
- `SCANNING`: 틱 수신 중 전략(MA5 돌파) 매수 시그널 검사.
- `ENTERING`: 매수 주문 발주 후 체결 대기.
- `HOLDING`: 체결 완료 후 포지션 등록, 익절 매도 주문 선등록(+3%) 및 물타기 감시.
- `EXITING`: 익절 체결 또는 마감 타임아웃에 의한 전량 매도 진행.
- `FAULT`: 네트워크 단절, 잔고 불일치 등 예외 시 슬롯 격리 및 알림.

### UC-AP-03: 장 마감 일괄 청산 (19:55 ET 타임아웃)
- 미국 동부시간 19:55 도달 시 모든 활성 슬롯에 마감 청산 이벤트 발행.
- 미체결 매수 주문 즉시 취소, 보유 수량 전량 매도 실행 후 `IDLE` 복귀.
