# 오토파일럿 (Autopilot) 도메인

> **오토파일럿**은 자동 단타 매매의 전체 라이프사이클을 조율하는 최상위 오케스트레이션 도메인입니다.
> 감시(SCANNING) → 진입(ENTERING) → 보유(HOLDING) → 청산(EXITING) 상태 전이를 관리하고, 다중 종목 동시 운용 한도, 시간대 세션 규칙, 예외 상황 격리(FAULT)를 책임집니다.

---

## 1. DDD 모델

### 엔티티 (Entity)
- **`AutopilotSession`**: 오토파일럿의 전역 활성화 상태(RUNNING, STOPPED), 실행 설정, 당일 통계를 유지하는 최상위 객체.
- **`SlotRunner`**: 개별 감시/매매 슬롯의 생명주기와 상태 머신(`SCANNING` → `ENTERING` → `HOLDING` → `EXITING` → `FAULT`)을 관리하는 식별 가능한 객체.

### 값 객체 (Value Object)
- **`SessionWindow`**: 정규장, 프리마켓, 애프터마켓, 마감 임박(19:55 ET) 등 거래 가능 시간대 판정 객체 (불변).
- **`CycleState`**: 슬롯의 현재 상태 enum (`SCANNING`, `ENTERING`, `HOLDING`, `EXITING`, `FAULT`, `IDLE`).
- **`ExitReason`**: 청산 발생 사유 (`PROFIT_TARGET_REACHED`, `MARKET_CLOSE_TIMEOUT`, `MANUAL_STOP`, `MAX_LOSS`).
- **`FaultDetail`**: 비정상 에러 발생 시의 원인 코드 및 격리 메타데이터.

### 애그리게잇 (Aggregate)
- **`AutopilotAggregate` (Root: `AutopilotManager`)**:
  - 전체 슬롯들의 집합을 제어하며, `maxConcurrent`(최대 동시 보유 종목수) 불변식을 엄격히 보장합니다.
  - 특정 슬롯에서 API 에러나 비정상 예외가 발생하더라도 전체 시스템이 멈추지 않고 해당 슬롯만 `FAULT`로 격리합니다.

### 도메인 서비스 (Domain Service)
- **`SessionGuardService`**: 현재 시각이 거래 허용 구간인지, 마감 청산 시점(19:55 ET)인지를 검증하여 일괄 청산 신호를 발행.
- **`SlotAllocationService`**: 랭킹 상위 종목 중 가용 자본과 동시 보유 한도 내에서 유휴 슬롯에 신규 종목을 할당.

## 3. 도메인 책임의 핵심 3원칙

1. **자기 완결성**: 외부 UI나 타이머가 상태를 강제로 바꾸지 않고, 오토파일럿 내부 규칙(틱 수신, 체결 확인, 세션 타이머)에 의해 스스로 상태 전이를 일으킵니다.
2. **비즈니스 규칙 보호**:
   - `maxConcurrent`를 초과하여 추가 매수가 일어나지 않도록 보장합니다.
   - 19:55 ET 도달 시 보유 중인 모든 종목은 신규 진입을 즉시 차단하고 전량 시장가/지정가 청산 루틴을 강제합니다.
3. **응집도 유지**: 상태 전이 로직과 데이세션 스케줄링, 안전장치(Circuit/Fault)가 하나의 도메인 경계 안에 응집되어 있습니다.

## 4. UI 모션 및 인터랙션 원칙 (Motion & Interaction Invariants)

1. **비침습적 60fps 보장**: 리스트 아이템의 재정렬(Reorder), 가격 카운트업, 인라인 게이지의 글라이딩은 웹소켓 수신 스레드와 발주 엔진 루프를 차단하지 않는 네이티브 드라이버/워크렛 기반으로 구동된다.
2. **연속적 시각 인지**: 틱 수신으로 순위나 가격이 변경될 때 순간이동(Snap)하지 않고 보간 애니메이션을 적용하여 사용자가 급격한 변동을 자연스럽게 추적할 수 있도록 지원한다.
3. **레이아웃 안정성 (Layout Shift Prevention)**: 틱 속도 변동이나 감시 후보 수 변경(`watched.length` 변동)과 같이 실시간으로 빈번히 토글될 수 있는 상태는 상단 고정 패널 내에 조건부 안내 문구를 동적으로 삽입/제거하지 않는다. 화면 높이가 요동치거나 버튼 및 리스트 위치가 덜컹거리는 시각적 불안정을 방지한다.
4. **수신 틱 시각화 격리 및 0-GC 뷰포트 게이팅**: 트레이딩 리스트 아이템의 수신 틱 웨이브 애니메이션은 메모리 할당/해제(GC)가 없는 고정 인스턴스 풀(3개)과 80ms 스로틀을 적용하며, 뷰포트에 표시 중인 아이템에서만 Native Driver로 구동된다. 화면 밖 종목 및 자동매매 주문 스레드(JS)에는 0%의 부하만을 허용한다.
