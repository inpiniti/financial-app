## 1. 사다리란
**주문 없는 가상 그리드로 "진짜 하락"을 판별하는 진입 감지기(BUY 전용).**
감시 시작가(트레일링 고점)를 앵커로, 간격 g%씩 떨어질 때마다 **홀**(가상 매수) 1회를 기록하고, 홀이 N번 쌓이면 바닥으로 인정해 BUY를 낸다. 누적 낙폭이 최소 N×g% 있어야 하므로 "찔끔 하락→찔끔 반등" 잔파동이 구조적으로 걸러진다 — SG 변곡점 감지기가 잔파동 바닥을 오판하던 문제의 해법(08-07).

## 2. 규칙
- 앵커 = 감시 시작가. 가격이 앵커 위로 오르면 앵커도 따라 올린다(트레일링).
- 직전 레벨 × (1−g) 도달 → 홀 +1, 레벨 갱신.
- 직전 레벨 × (1+g) 반등 → 가상 익절로 보고 **리셋**(홀 0, 신호 없음).
- 홀 == triggerCount → BUY 발화 후 리셋.
- BUY 게이트(거래량 스파이크·체결강도)는 변곡점 감지기와 같은 계약: 입력 null이면 통과(fail-open), 게이트만 막았으면 `buyGateBlocked`로 UI 배지.
- 입력은 리샘플 청크 마감가(3초) — 감지 주기가 SG 감지기와 같다.
- 기본값 g=1%, N=3.

## 3. 사다리 그리드 시도와 롤백 (2026-08-14)
사다리 논리를 체결 후 관리(배수 물타기 그리드)에도 쓰려던 시도는 올인을 겪고 같은 날 배수 물타기로 복귀 → 이후 08-15 고정 수량 물타기로 최종 확정(ADR 0001). 사다리는 **진입 감지 전용**으로만 남는다.

## 4. 용어
- **홀**: 사다리의 가상 매수 카운트 1회 (= 누적 낙폭 g% 진행).
- **레벨**: 마지막 가상 매수가(홀 0이면 트레일링 고점).
- **리셋선**: 레벨 × (1+g).
