# 기울기/초 표시 + 속도·기울기/초 5칸 시계열 — plan

> 작성일 2026-08-14 · 상태: **구현 완료(같은 날)**
> 정본 개념: `docs/domain/기울기/2026-08-14_기울기-초-개념과-설계.md`

## 요구

1. 트레이딩 리스트에 **기울기/초**(%/초) 표시 — 지금은 속도(틱/초)만 보인다.
2. 속도·기울기/초 모두 현재값 1개가 아니라 **[4초전, 3초전, 2초전, 1초전, 현재] 5칸**을 표시.

사용자 확정:

- 표시 형태 = **숫자 5개 나열**(행 아래 두 줄. 스파크라인·현재값만 병기 안 선택).
- 폴링 = **2초 유지**(시계열이 2초마다 2칸씩 밀리는 것 수용. 1초 폴링 안 선택 — 리렌더·배터리).

## 핵심 설계 결정

| # | 결정 | 이유 |
|---|---|---|
| 1 | 타이머·스냅샷 링 없이 **조회 시점 되계산** | 배터리 1급 제약. 미터가 원시 이력을 `windowMs + historyMs(4초)`만큼 보존하면 과거 시점 값은 구간 스캔으로 언제든 재현된다 |
| 2 | `TickRateMeter` 값 계산을 큐 잔량 → **(t−W, t] 구간 카운트**로 변경 | 종전 프루닝은 파괴적이라 과거 시점 조회 불가. 구간 카운트면 현재값 결과 불변 + 과거 조회 가능(기존 테스트 8개 무수정 통과가 회귀 기준이었고 실제 통과) |
| 3 | `SlopeMeter`는 개념 문서 §3 정본 그대로 | 양끝점, 분모=실경과초, 스팬<1초 null, null≠0 |
| 4 | 시계열은 `getView()`에서 계산 | 소비자가 2초 폴링으로 읽어도 각 칸은 폴링 시점 기준 정확. 폴링 주기·emitList 경로 무변경 |
| 5 | UI 라벨 "속도" / "기울기/초" | 단독 "기울기" 금지(개념 문서 §2 — SG %/청크와 혼동) |

## 변경 파일

- `features/scalper/tickRate.ts` — `historyMs`(기본 4초) 보존, `rate()` 구간 카운트화, `series(nowMs, points=5, stepMs=1000)` 추가.
- `features/scalper/slopeRate.ts` **신규** — `SlopeMeter`: `record(atMs, price)` / `rate(): number|null` / `series()` / `reset()`. 상수 `DEFAULT_SLOPE_WINDOW_MS=10_000`, `DEFAULT_SLOPE_MIN_SPAN_MS=1_000`, `DEFAULT_SLOPE_HISTORY_MS=4_000`.
- `features/scalper/feedSlot.ts` — `pushTick()`에서 상시 기록(attach 무관), `FeedSlotView`에 `slopeRate` / `tickRateSeries` / `slopeRateSeries` 추가. 기존 `slope`(SG %/청크)와 별개 필드.
- `features/scalper/ui/format.ts` — `formatSlopeRate`(부호+소수1자리, null→'—') / `formatTickRateSeries` / `formatSlopeRateSeries`.
- `features/scalper/ui/AutoPilotScreen.tsx` — `SlotRow` 부제를 3줄 ReactNode로: 티커·출처 / `속도 0.8 1.2 2.0 1.5 1.8` / `기울기/초 +0.1 -0.2 — +0.2 +0.3` (tabular-nums, `#8b95a1`). 부제 1줄의 `N.N틱/초`는 시계열 줄로 이동.
- `features/scalper/index.ts` — 배럴 export.
- 테스트: `slopeRate.test.ts` 신규 14개, `tickRate.test.ts` +2(시계열·이력 한계), `feedSlot.test.ts` +1(뷰 노출).

## 하지 않은 것

- 폴링 주기 변경(2초 유지), 설정 화면 노출(윈도우는 코드 상수), 감시 선정·매매 로직 투입(표시로 관찰 먼저 — 개념 문서 §6), 헤더 요약 문구 변경.

## 주의 (재수정 시)

- `series()`의 과거 조회 가능 폭은 `historyMs`까지 — 그보다 먼 시점은 프루닝으로 과소 집계된다(테스트에 명시). 칸 수·간격을 늘리면 `historyMs`도 같이 늘릴 것.
- `slopeRateSeries`의 null은 '—'로 그린다. 0으로 그리면 "모름"과 "횡보"가 섞인다(개념 문서 §3).
