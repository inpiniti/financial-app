## 1. 그리드란

**포지션(보유수량 N·평단 P)이 생긴 뒤 "얼마에 더 사고(물타기), 얼마에 팔 것인가(익절)"를 정하는 규칙**. 진입 타이밍(신호)도, 체결 방법(실행)도 그리드 몫이 아니다.

- 매수선 = P × (1 − 매수폭) — 물타기
- 매도선 = P × (1 + 매도폭) — 익절
- 물타기 체결 → N↑·P↓ → 두 선을 새 평단 기준으로 다시 잡는다(재브래킷).
- 익절 체결 → 전량 정리 → 오토파일럿이 SCANNING 복귀.

## 2. 두 구현 — 주문을 미리 걸 것인가

| | 매도그리드 (`core/grid`) | 조건부 그리드 (`core/conditional`) |
|---|---|---|
| 상태 | ARMED 동안 매수·매도 지정가를 **항상 걸어 둠**(OCO) | 지정가 없음. 평단·수량만 들고 있음 |
| 언제 움직이나 | 지정가가 붙으면 | 신호(추세/변곡점 SELL·BUY)가 왔을 때만 문턱을 판정 |
| 매도 조건 | 매도선 도달 = 체결 | SELL 신호 & 평단 대비 ≥ +sellProfitPct → 전량 매도, 미만이면 홀딩 |
| 매수 조건 | 매수선 도달 = 체결 | BUY 신호 & 평단 대비 ≤ −buyDropPct → 최초 진입 수량만큼 매수 |
| 상태 | `IDLE / ARMED / SOLD / FAULT` (+ 내부 REBRACKET) | 상태 없음(순수 판정기) |
| 사용처 | 변곡점 시절 관리 경로. 현재 `TREND_MODE=true`에서는 조건부 그리드 사용 | 변곡점+그리드 조합(08-15) 이후 정본, 추세 모드도 이걸 씀 |

역할 분담(08-15 확정): **신호=타이밍, 그리드=조건·포지션 판정, 매매=체결 실행**. 조건부 그리드의 결정(`ConditionalDecision`)은 side·qty(+서킷용 limitPrice/chaseAfterTradeAt)만 담고 실행은 `core/execution`에 넘긴다.

## 3. 규칙 (정본)

### 3-1. 비대칭 폭 (2026-08-14)
매수폭과 매도폭은 **따로 설정**한다(기본 매수 5% / 매도 2% / 매수 배율 1). 물타기 간격을 넓게 잡아 올인을 늦추고, 익절 목표를 좁게 잡아 반등 요구폭을 줄이는 것이 목적. 배율은 매수수량 = floor(N×배율), 매도는 항상 N 전량.

### 3-2. 고정 수량 물타기 (2026-08-15) → ADR 0001
물타기 수량은 **최초 진입 수량 고정**. 배수(2배) 마틴게일은 08-14 사다리 그리드 시도에서 올인을 겪고 배제. 횟수 상한은 두지 않는다 — 고정 수량이라 자금 소모가 선형이고, 현금 부족이면 그 매수만 축소·건너뜀(`BuyLegStatus: full/reduced/skippedCash`).

### 3-3. 급락 방어 매수 앵커 (2026-08-14) → ADR 0002
매도그리드에서 `buyLegDelayMs>0`이면 매도 다리는 즉시, **매수 다리는 지연 후 그 시점의 min(평단, 현재가)×(1−매수폭)**에 건다. 평단 단독 앵커는 장대음봉에서 매수 지정가가 시장가 위에 걸려 접수 즉시 체결 → 연쇄 물타기가 났다. 평단 단독 앵커로 회귀 금지.

### 3-4. OCO
한쪽 체결 시 반대편을 **실제 취소**한다. 취소 거절은 "이미 체결" 신호일 수 있어 폴의 실측이 판정한다(매매 도메인 §4와 같은 원칙).

### 3-5. 동시 그리드
종목별로 그리드 인스턴스 1개. 동시 개수 상한 `maxConcurrentGrids`(기본 1). 한 그리드의 FAULT는 그 그리드만 격리한다(오토파일럿 문서 §4).

## 4. 용어
- **앵커**: 선을 계산하는 기준가. 매도그리드 매수 다리 = min(평단, 현재가), 매도 다리 = 평단.
- **재브래킷(REBRACKET)**: 물타기 체결 후 잔고 재조회 → 새 평단으로 두 선 재설정.
- **매수선/매도선(buyLine/sellLine)**: 조건부 그리드의 문턱선. 지정가가 아니라 "이 선을 넘긴 신호만 유효"의 조건.
