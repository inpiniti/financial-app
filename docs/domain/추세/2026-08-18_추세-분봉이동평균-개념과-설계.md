## 1. 추세란

**분봉 종가의 단순이동평균(SMA) 4선** — 분봉5선·분봉20선·분봉60선·분봉120선 — 을 묶어 부르는 이름. 각 선의 시점 t 값은 "t까지의 최근 N개 분봉 종가 평균"이다.

```
분봉N선(t) = (close[t−N+1] + … + close[t]) ÷ N     (N = 5, 20, 60, 120)
```

- 1분봉 기준으로 분봉5선은 최근 5분, 분봉120선은 최근 2시간의 평균 — 단기→장기 시야를 4단계로 본다.
- 기울기/10초가 "지금 이 순간 어느 방향인가"(초 시야)라면, 추세는 "이 종목이 분 시야에서 어느 위치에 있나"를 본다. 두 지표는 시야가 달라 서로 대체하지 않는다.

## 2. ⚠ 용어 — "일선"이라 부르지 않는다

HTS 습관으로 "5일선·20일선"이라 부르기 쉽지만, **일선(日線)은 일봉 N일 평균**을 뜻하는 말이라 분봉 차트의 선과 혼동을 부른다. 이 앱의 정본 용어:

- **분봉5선 / 분봉20선 / 분봉60선 / 분봉120선** — 최근 N개 **분봉** 종가의 평균. 코드 식별자는 `ma5`·`ma20`·`ma60`·`ma120`.
- "5일선"(일봉 5일 평균)이 필요해지면 그때 별도 개념으로 정의한다 — 데이터 소스도 다르다(`kis/periodChart.ts` 일봉).

## 3. 정의 (정본)

- 입력: 시간 **오름차순**(과거→최신) 분봉 **종가** 배열. `kis/minuteChart.ts`가 이미 오름차순 정렬해 준다.
- 봉이 N개 미만이거나 창 안에 비유한값이 있으면 그 시점 값은 **null**. **null ≠ 0** — "판정 불가(모름)"와 "평균이 0"을 혼용하지 않는다(기울기 도메인과 동일 원칙).
- 가중 없음 — 단순 평균(SMA)이다. EMA 등 가중 평균은 이 도메인의 범위 밖.

## 4. 데이터 수급 — 분봉조회 첫 페이지로 충분

분봉조회는 한 번에 최근 **120건**까지 준다(첫 페이지, NEXT/KEYB 다음조회 미구현 — `kis/minuteChart.ts` v1 범위 그대로).

- **120봉 = 분봉120선 최신값 1개에 정확히 필요한 양** — 스냅샷(현재 4선 값) 용도는 호출 1번으로 끝난다.
- 4선의 **시계열**(차트에 선 그리기)이 길게 필요하면 다음조회가 필요하지만, v1은 스냅샷이 목적이므로 구현하지 않는다.
- PINC(전일포함)는 호출부 판단 — 장 시작 직후 당일 봉이 120개 미만이면 전일 포함("1")으로 채우는 쪽이 자연스럽다.

## 5. 구현 — `core/trend` (2026-08-18 v1)

순수 TS, 외부 의존 0 — RN/KIS를 모른다. 호출부가 `MinuteCandle[]`에서 `close`만 뽑아 넘긴다.

- `TREND_PERIODS = [5, 20, 60, 120]` — 기간 고정, 설정 옵션 아님.
- `smaSeries(closes, period)` — 입력과 같은 길이의 시계열(창 덜 참·비유한값 → null). 롤링 합으로 O(n).
- `latestSma(closes, period)` — 마지막 시점 값 하나.
- `computeTrend(closes)` — `{ ma5, ma20, ma60, ma120 }` 스냅샷. 봉이 모자란 선만 각각 null(60봉이면 분봉120선만 null).
- `computeTrendSeries(closes)` — 4선 시계열(차트용).
- 단위 테스트: `core/trend/index.test.ts` (창 워밍업 null, NaN 창 오염·복구, 120봉 4선 완성, 부분 null).

## 6. 활용 (2026-08-18 배선됨)

1. **종목 상세 차트에 4선 표시** — `features/stock/ui/ChartPanel.tsx` 분봉 모드에 `computeTrendSeries` 오버레이(2026-08-18). REST 120봉 기준이라 분봉120선은 마지막 봉 근처만 그려진다.
2. **감시 시작 시 추세 스냅샷** — 감시 편입 "초반에" 분봉조회 1회로 `computeTrend`를 떠서 종목의 위치(현재가 vs 4선, 정배열 여부)를 참고 정보로.
3. **매매 판정 입력** — 검토 기록: `2026-08-18_추세-타점-상승여부-전략-검토.md` → **2026-08-18 구현**(`2026-08-18_추세-그리드-매매-조합-plan.md`): 4선 상승 2봉 연속·종가>분봉60선 진입, 분봉5선 꺾임 전량 청산. 봉은 WS 체결가 합성(`core/trend/bars.ts`) + 분봉조회 시드.

정배열/역배열 같은 레벨 순서 **판정**은 도메인에 없다. 방향(기울기 부호) 기반 신호는 `core/trend/signal.ts`(`evaluateTrend`)에 있다 — 4선 값(index.ts)과 신호(signal.ts)를 파일로 나눴다.
