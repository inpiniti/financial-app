# 리샘플 청크와 BUY 게이트 — 판정 입력의 정의

> 작성일 2026-08-19 · 분류: **도메인 문서** (변곡점·사다리 감지기가 공유하는 입력 규칙)
> 코드: `core/resample/index.ts`(`Resampler`), `core/detector/index.ts`(`GateInput`), `core/ladder/index.ts`

## 1. 청크 (리샘플)
WS 체결 틱(초당 수십 건)을 직접 연산하지 않고, **청크 초(3초) 동안의 평균가 1개**로 줄여 홀수 크기 원형 버퍼(31, SG 창)에 유지한다. 청크가 판정 주기다.
- 청크·버퍼는 2026-08-08 이후 조절 옵션이 아니라 고정값(`DEFAULT_CHUNK_SECONDS=3`, `DEFAULT_BUFFER_SIZE=31`).
- 청크별 거래량 합·마지막 체결강도도 같은 타이밍에 쌓인다(게이트 입력).
- 틱의 volume/strength는 유한값일 때만 집계 — 없으면 그 청크는 null(0이 아님).

## 2. BUY 게이트
BUY 신호에 거는 AND 필터 두 개: **거래량 스파이크 배수**(minVolumeSpikeRatio) · **체결강도**(minStrength, KIS STRN, 100=균형).
- 0이면 끔.
- **입력이 null(판정 불가)이면 통과(fail-open)** — 데이터 유실이 매매를 전면 중단시키지 않게. 게이트만 BUY를 막았으면 `buyGateBlocked`로 UI 배지.
- 변곡점(SG)·사다리 감지기가 같은 계약(`GateInput`)을 쓴다.

## 3. 오토파일럿의 속도 게이트와 다르다
오토파일럿의 `minTickRate`(틱/초) 게이트는 "종목이 활발한가"의 진입 자격이고, BUY 게이트는 "이 신호가 믿을 만한가"의 신호 필터다. 둘 다 통과해야 진입한다.
