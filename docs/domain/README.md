# 도메인 지도 (docs/domain)

> 작성일: 2026-09-11  
> financial-app 프로젝트의 도메인 주도 설계(DDD) 기반 정본 도메인 지도입니다.  
> 모든 자동매매 거래 규칙, 불변식(Invariants), 세션 시간표 및 상태 머신은 `docs/domain/` 하위의 개별 도메인 문서가 유일한 정본(Single Source of Truth)입니다.

---

## 3. 도메인 설계 원칙

1. **자기 완결성**: 외부 UI나 타이머가 상태를 강제로 바꾸지 않고, 도메인 객체 내부에서 자체 비즈니스 로직을 직접 수행합니다.
2. **비즈니스 규칙 보호**: 불변식(Invariants)을 위반하는 상태 전이(가용 자본 초과 매수, 감시 종목 30개 초과, 보유량 초과 매도, 14:00 이후 신규 진입 등)를 원천 차단합니다.
3. **응집도 유지**: 데이터와 해당 데이터를 변경하는 행위/로직을 하나의 도메인 경계 안에 결합합니다.
