# 2026-09-01 — 물타기 vs "물타기 없음 + −3% 손절" 비교 (마틴게일 모드 닷새, 55건)

사용자 질문: "1주 거래 21건·물타기 13건 — 물타기 없이 가는 게 오히려 금전적 이득 아닌가?" + 요청(주간거래 제외, 물타기 제거, −3% 손절 전환).

## 1. 데이터

- 원본: [분석용 데이터/2026-09-01.csv](분석용%20데이터/2026-09-01.csv) — `trade_results` 157건 중 **strategy=martingale 55건**(2026-08-27~08-31, 메인 계좌 45건 +$16.46 / 소액 계좌 10건 +$0.27).
- 물타기 발생 판정: 평단(entry_price) < 최초 진입가(entry_snapshot.price)×0.995 — 12건(qty=1인 NCRA 1건은 스냅샷 갱신 오탐으로 제외 시 11건. 재시작 복원으로 스냅샷이 갱신된 건은 못 잡는다 — 소폭 과소집계).

## 2. 결과 — 물타기가 이 기간 수익의 80%를 만들었다

| | 실제 | 가정(물타기 없음 + −3% 손절) |
|---|---|---|
| 물타기 발생 12건 | **+$13.37** | **−$0.54** |
| 물타기 없던 43건 | +$3.36 | +$3.36 (동일 가정) |
| 합계 | **+$16.73** | **+$2.82** |

- 첫 물타기 발동 조건이 "평단 −3% 이하"라, 물타기 발생 건은 전부 −3% 손절선을 먼저 건드린 거래다 → 새 규칙이면 12건 전원 손절. 실제로는 **12건 전부 회복해 이익 종결**(CELU +$5.20, AIM +$4.21이 절반 이상).
- 8/31 하루만 봐도 동일: 50건 실제 +$11.10 vs 가정 +$2.46(물타기 11건 +$8.17 vs −$0.47).
- 가정의 낙관 편향: 물타기 없던 43건 중에도 익절 전 −3%를 스쳤다 회복한 건이 있을 수 있으나 체결 기록만으론 알 수 없어 그대로 뒀다 — 실제 손절 방식 성과는 +$2.82보다 낮을 가능성.

## 3. 손절선 −4%/−5% 변형 — 차이 없음, 오히려 악화

물타기 평균 체결가 = (Q×평단 − 최초가)/(Q−1)로 각 건의 **최소 낙폭**을 역산(여러 번 나눠 샀으면 실제 최저가는 더 낮다 — 하한 추정):

| 손절선 | 물타기 발생 11건 합(최초 1주 기준) |
|---|---|
| 실제(물타기) | +$13.27 |
| −3% | −$0.43 |
| −4% | −$0.57 |
| −5% | −$0.67 |

11건 중 **9건이 최소 −7.5% ~ −26%**(CELU −21%, AIM −26%, GMHS −25%, VVOS −19%, SST −14%…)까지 떨어졌다 회복 — 3~5% 어디에 손절선을 둬도 똑같이 잘리고 손실 폭만 커진다. −5%에서 살아남을 가능성은 GPRO(−4.9%) 1건뿐.
