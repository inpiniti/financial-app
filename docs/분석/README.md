# 분석 → 수정 개선 일지

> 운영 방식(2026-08-19 확정): 사용자가 실거래 데이터(`trade_results` CSV 등)를 넘긴다 → 토스 분봉 등으로 재현·비교 분석 → 근거가 선 것만 코드로 수정 → **분석 문서 1건 + 이 일지에 1줄씩** 남긴다.
> 받은 원본 데이터는 `분석용 데이터/YYYY-MM-DD.csv`(받은 날짜)로 함께 커밋한다. 분석 문서는 `YYYY-MM-DD_주제.md`, 이 일지는 날짜 역순으로 "받은 데이터 · 분석 결과 · 바꾼 것(커밋) · 안 바꾼 것과 이유 · 다음에 볼 것"을 적는다.
> 절대 수치보다 **변형 간 상대 비교**로 판단하고, 하루치로 뒤집지 않는다. 판단이 뒤집힌 항목은 지우지 않고 취소선으로 남긴다.
> 날짜 관례: **거래일 = 미국 거래일(ET 날짜)**, 문서 파일명·일지 날짜 = 작성일(KST). CSV `entry_at`은 UTC — 세션 구분(프리 04:00~09:30 / 정규 09:30~16:00 / 애프터 16:00~20:00 / 오버나이트 20:00~04:00 ET)은 ET로 환산해 판단한다. 토스 분봉 `dt`는 ET 오프셋 포함.
