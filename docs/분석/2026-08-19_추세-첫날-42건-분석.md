## 4. AIXC — 기록 안 된 수동 청산

정규장 개장 직후 0.75 → 22:33 1.19 → 서킷(LULD) 정지 반복: 1.19(9분 정지) → 1.51(5분) → 1.77(4분) → 1.93 → 1.69(하킷) → … → 2.95. 각 정지 구간은 거래량 0 봉이 5~9개 연속.

- 정지 중엔 체결이 없어 우리 봉이 안 닫히고(틱 주도), 재개 순간 봉 하나가 갭으로 닫힌다 → ma5 판정이 갭 뒤에 나오고, 매도 주문은 정지 중엔 체결이 안 된다. 즉 **서킷 종목은 규칙이 시간축에서 작동을 못 한다.** 사용자가 하킷에서 수동 매도한 게 맞는 처리였다.
- 코드로 할 수 있는 건 "감지"뿐: 직전 봉 대비 갭 ≥ X% 또는 N초 무체결 뒤 갭 재개 → 그 종목 당일 진입 금지(진입은 막을 수 있어도 보유 중 서킷은 못 피함). 우선순위 낮음 — 하루 1종목.

## 5. 결론 · 의견

1. **정규장만 돌릴까?** 실거래 5건과 1분 재현은 정규장이 좋고, 3·5분 재현은 반대다. 하루치로는 결론이 안 난다. 세션을 자르는 것보다 **거래 수를 줄이는 게** 모든 변형에서 일관되게 좋았다. 세션 결정은 며칠 더 쌓고.
2. **가장 확실한 개선 = 봉 주기 3분(또는 5분).** 슬리피지가 실측 0.65%인 이상 1분봉 ma5는 구조적으로 비용을 못 이긴다. 3분봉은 같은 규칙·같은 코드(봉 빌더 분 키만 3분 버킷, 시드는 토스 min:3)로 바꾸는 작은 변경이고, 이 날 데이터에선 1분 대비 거래 1/3·건당 이익 4배·"우상향 종목 반복 털림" 해소. 5분은 더 좋게 나왔지만 워밍업이 10시간(122봉)이라 세션 초반을 통째로 놓친다 — 3분(6시간, 토스 시드로 채움)이 현실적.
3. **청산은 "종가<ma5"가 "ma5 꺾임"보다 모든 봉 주기에서 승률·합계가 높았다.** 1~2봉 빠르게 나가고 반등이면 다시 탄다(재진입은 그대로). 3분봉으로 가면 같이 바꿀 만함.
4. **손절선은 −5% → −7%로 완화 검토.** 재현에선 −5%가 꼬리에 찍혀 반등을 놓치는 비용이 있고, −7%부터 그 비용이 거의 사라지면서 최악은 −13%로 잘린다(3분봉 기준). 3분봉이면 봉 안 노출이 3분이라 손절선의 역할이 더 커진다.
5. **개장 10~15분 진입 금지**는 작지만 일관된 플러스. 프리마켓 17:00과 정규장 22:30 둘 다.
6. **재진입 앵커는 기각**(PFSA류 정상 재진입까지 막음). 사용자가 걱정한 "놓친다"가 맞았다.
7. **풀타임 vs 정규장만**: 3분봉 + 종가<ma5 + 손절 −7% + 개장 15분 제외로 바꾸면 이 날 재현은 전 세션 양수라 풀타임을 유지해도 된다는 쪽. 다만 이건 하루·사후 선택 종목이라, 바꾼 뒤 며칠 1주로 다시 표본을 모으고 세션별로 나눠 보는 게 순서.

## 6. 데이터 한계(정직하게)

- 하루치. 종목은 그날 실제 매매된 것 = 그날 움직인 종목만 → 절대 수익률은 못 믿고 변형 간 상대 비교만.
- 재현 체결 = 다음 봉 시가, 슬리피지 0. 실측 0.65%/진입을 별도 열로 차감해 보정했지만 청산 슬리피지는 프리마켓 급락에서 훨씬 클 수 있다.
- 토스 봉은 무체결 분도 채워져 있다(앱의 틱 주도 봉과 다름). SMA에 미세한 차이.
- 서킷 종목(GNPX −37%, AIXC)은 어떤 규칙으로도 못 막는다 — 최악값은 규칙 탓이 아니라 종목 탓.
