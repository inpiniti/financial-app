# 수동 단타 카드 제거 plan (2026-08-08)

## 배경·목표

홈 화면의 "수동 카드" 모드(카드 리스트·개별 Run/Stop)는 더 이상 쓰지 않으므로 제거한다.
단, **자동 단타·종목 상세화면·손익 조회가 수동 카드 코드에 깊게 얽혀 있어** 무턱대고 지우면 깨진다.
원칙: **다른 기능이 의존하는 것은 남기고, 수동 카드 전용인 것만 없앤다.**

## 조사 결과 — 얽힘 지도

`ScalperManager`는 이름과 달리 두 역할을 겸했다:

1. **수동 카드 기능** (제거): 인스턴스 CRUD·영속화(`scalper:instances`)·개별 Run/Stop·오토런/마틴게일 토글.
2. **WS 피드 허브** (유지): 실시간 WS 연결의 **유일 소유자**. `routeTick/routeQuote`가
   자동 단타(`setAuxRoutes`)·시뮬레이션(`simExchange`/`simLab`)·종목 상세화면(`subscribeFeedData`)으로
   틱·호가를 분배하고, `acquireFeed/releaseFeed`(상세화면 refcount)·`holdsFeed`(자동 단타 교차 해제 방지)·
   `reportFeedError`·`getSubscriptionStatus`(구독 ACK 진단)를 제공한다.

그 외 의존:

- `features/inquiry/ProfitLoss.tsx` → `tradeStore` — 수동 카드의 과거 거래 기록도 읽는다 → 기록·저장소 유지.
- `app/stock/[ticker].tsx`의 + 버튼 = "수동 카드 추가" → 카드와 함께 제거.
- `autopilotManager.start()`의 수동/자동 상호 배타 가드(`isManualBusy`) → 수동이 없으니 제거.
- `app/settings.tsx` "주문 수량"(`orderQty`) = 수동 카드 폼 기본 수량 전용 → UI만 제거, 저장 필드 유지(마이그레이션 불필요).
- `__tests__/e2e` = 수동 경로 전용 통합 검증 → 자동 경로 e2e가 없으므로 하네스를 자동 경로용으로 개조.
- 홈의 연결 배지·진단 줄·실행 배너는 원래 수동 분기에서만 렌더 → 제거해도 자동 화면이 잃는 것 없음.

## 실행 내역

### Phase 1 — UI 진입점 제거

1. `app/home.tsx`: 수동/자동 세그먼트(`ModeSwitch`)·manual 분기 삭제 → `AutoPilotScreen` 단독 화면.
2. `app/stock/[ticker].tsx`: "+ 수동 카드 추가" 버튼·`AddInstanceSheet` 제거.
3. 컴포넌트 삭제: `InstanceCard`·`AddCard`·`AddInstanceSheet`·`EditQtySheet`·`RunningBanner`.
4. `app/settings.tsx`: "주문 수량" 입력란·"수동 단타 카드는 항상 실거래" 문구 제거(`orderQty` 필드는 저장 유지).

### Phase 2 — 로직 정리

5. `scalperManager.ts`: 피드 허브만 남긴다 — 카드 CRUD·영속화·Run/Stop·keep-awake·`anyRunning`·
   `MAX_INSTANCES` 제거, `acquireFeed/releaseFeed`의 카드 검사(`cardUsesTrKey`) 제거. deps는 `{realtime, clock}`.
6. `scalperInstance.ts`(+테스트) 삭제 — 자동 단타는 `core/cycle`·`feedSlot`을 직접 쓴다.
   (`nextAutoRunQty` 등 수동 전용 규칙도 함께 삭제. `scalperInstance.test.ts`의 "본전 규칙 자동/수동 차이"
   비교 케이스는 수동 쪽 소멸로 의미가 없어짐 — 자동 쪽 규칙은 `autopilot.test.ts`의 `nextAmountUsd`가 검증.)
7. `autopilotManager`: `isManualBusy` deps·start 거부 가드 제거(+테스트 케이스 제거).
8. `managerProvider`: 수동용 `makeBroker`·`restore()`·`defaultQty`/`bufferSize`/`chunkSeconds` 노출 제거.
   realtime→허브→autopilot 생성·배선 순서는 유지.
9. `features/scalper/index.ts` 배럴에서 수동 전용 export 제거.
10. e2e: 수동 경로 테스트 삭제, 하네스를 자동 경로용으로 개조(`autopilot.e2e.test.ts`) —
    WS 프레임 파싱→허브 라우팅→슬롯 판정→실물 REST 글루(주문 TR ID·수량·tradeStore 기록) 검증 유지.

## 유지(자동 단타·상세화면·손익 영향권)

`ScalperManager` 피드 허브 전부, `tradeStore`+기존 기록, `core/*`·`feedSlot`·`createKisBroker`·
`createRealtimeFeed`·`simBroker/simLab`·`keepAwake`, `AmountSheet`·`AdoptSheet`·`GridGauge`·`format.ts`·
`BottomSheet`·`ToggleRow`, `appSettings.orderQty` 필드.

## 잔재(무해)

- AsyncStorage `scalper:instances` 데이터 — 읽는 코드가 없어 무해. 정리는 하지 않았다.
- 수동 카드의 과거 거래 기록(`trades:YYYY-MM-DD`)은 손익 화면 데이터라 삭제하지 않는다.
