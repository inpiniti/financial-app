# 홈 메뉴 재구성 + 종목검색 화면 (2026-08-10)

## 배경

기존 구조는 홈 = 트레이딩 화면, 조회 = 별도 화면(하단 메뉴 5개: 보유종목/미체결/순위/손익/거래기록)이었다.
자주 쓰는 섹션이 조회 화면 안에 숨어 있어 접근이 멀고, 거래기록은 트레이딩과 붙어 있는 것이 자연스럽다.

## 변경 내용

### 홈 — 하단 고정 메뉴 4개 (`app/home.tsx`)
- `BottomMenu`로 **트레이딩 / 보유종목 / 순위 / 손익** 섹션을 화면 안에서 전환(옛 조회 화면 패턴 이식).
- 스캘퍼 매니저 부트스트랩(loading/needsSetup/error)은 **트레이딩 섹션만** 게이팅 — 키 미설정이어도 다른 섹션 이동 가능.
- 손익 일별 상세(`onDetailOpenChange`)가 열리면 상단바·하단 메뉴 숨김(기존 조회 화면 동작 계승).
- 상단바 좌측 아이콘은 검색(`/search`)으로 진입.

### 보유종목 + 미체결 병합 (`features/inquiry/HoldingsAndPending.tsx`)
- `Holdings.tsx`/`PendingOrders.tsx`를 각각 **데이터 훅(useHoldings/usePendingOrders) + 스크롤 없는 패널(HoldingsPanel/PendingOrdersPanel)** 로 분리하고, 섹션이 ScrollView 하나에 위아래로 쌓는다.
- KIS 세션은 섹션 레벨 `useKisSession` 1회 공유, 당겨서 새로고침 한 번으로 잔고·미체결 동시 갱신.
- 미체결 취소는 미체결만 재조회(잔고 요청 없음).

### 거래기록 → 트레이딩 섹션 하단 (`features/inquiry/TradeHistory.tsx`)
- `useTodayTrades(reloadKey)` 훅 + `TradeHistoryPanel`(스크롤 없는 패널)로 리팩터.
- `AutoPilotScreen`의 `ListFooterComponent`에서 "기록" 패널 뒤에 렌더 — 바깥 FlatList와 스크롤 중첩 없음.
- `view.cycles`가 늘 때마다(사이클 완료) 자동 재로드.

### 조회 → 검색 (`app/search.tsx` 신규, `app/inquiry.tsx` 삭제)
- 티커·종목명(한글/영문) 입력 → 300ms 디바운스 → 결과 목록 → 선택 시 종목상세 진입.
- 데이터 소스: 토스 자동완성 비공식 API(`lib/tossSearch.ts`). `lib/tossCommunity.ts`가 이미 쓰는 v2 엔드포인트와 동일 — 로그인·특수 헤더 불필요(curl 실호출 확인).
  - 응답 market `NSQ/NYS/AMX`만 채택(국내 `KSP/KSQ` 제외), `NSQ→NAS, NYS→NYS, AMX→AMS` 매핑 → 기존 `toStockMarketCode` 호환.
- 연타 시 이전 응답 잔상 차단: `requestSeqRef` latest-wins(손익 월 연타 수정과 동일 패턴).
- 종목상세 뒤로가기는 기존 그대로 `router.back()` — 검색에서 왔으면 검색 결과 유지, 홈에서 왔으면 홈.

### 정리
- `app/_layout.tsx`: `inquiry` → `search` 스크린 교체.
