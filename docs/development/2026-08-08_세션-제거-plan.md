## 1. 제거 전 상태 — 세션은 이미 사실상 죽어 있었다

- 실제 진입금액은 `config.startAmountUsd` 단일 소스(다중 그리드 이후). `session.amountUsd`는 회계·문구용.
- AmountSheet가 저장 시 항상 `martingale: false`로 정규화 → UI 경로로는 배증/반감·세션 완주가 발생하지 않음.
- **따라서 세션 제거는 매매 동작(진입금액·수량·그리드·신호)에 영향 없음** — 사전 검증 완료.
- 유일한 강결합: PAUSED(현금부족)가 `session.paused`에서 파생 → 독립 플래그로 이관 필요.

## 2. 변경 내용

### 제거
- `SessionState`·`session`·`sessionCount`, `nextAmountUsd`·`shouldEndSession`·`isMartingaleOn`·`AMOUNT_FLOOR_USD`
- config의 `martingale`·`maxAmountUsd` (+ validateConfig의 최대금액 검사)
- `resetSession()` — PAUSED 탈출은 `resume()` 하나로 통일
- UI: 세션 패널·"세션 N개" 표시·"세션 초기화하고 재개하기" 버튼, 배럴(index.ts) 재수출

### 유지
- `startAmountUsd`(진입금액 — 저장 키 이름은 하위호환으로 유지)·`minTickRate`·`maxConcurrentGrids`
- **PAUSED**: 독립 `private paused` 플래그로 이관. 트리거(현금부족)·자동 재개 금지·재시작 복원 전부 동일.
- `daily { date, cycles, cumPnl }` (오늘 성과, ET 기준일 롤오버)
- 수동 카드(scalperInstance)의 수량 마틴게일 — **별개 기능, 무관**

### 영속 v3 + 마이그레이션
```
PersistedV3 { version: 3, config { startAmountUsd, minTickRate, maxConcurrentGrids }, paused, daily { date, cycles, cumPnl } }
```
- v2 → v3: config에서 maxAmountUsd·martingale 폐기, `paused = session.paused` 승계(입금 대기 상태 보존), sessionCount 탈락.
- v1 → v3: `startAmountUsd = baseAmountUsd`, `minTickRate = 1`.
