# 변곡점 감지 교체 — 가상 그리드 사다리(홀 카운트) 진입

> 작성일 2026-08-07 · 분류: **중형** (감지 코어 신설 + 감시 배선 교체 + 설정 2개 — 주문 경로·매도그리드는 그대로)
> 기준: 감지 코어 `core/detector/index.ts`(SG 기울기), 매도그리드 `core/grid/index.ts`, 배선 `features/scalper/feedSlot.ts`·`autopilot.ts`

## 1. 문제 — 지금의 변곡점은 왜 틀리나

현행 변곡점은 Savitzky-Golay 1차 미분의 **부호 전환**(−→+)이 기본 트리거다. 모멘텀 문턱(기본 0.01%/청크)이 있긴 하지만, 이 문턱은 "전환 직후 기울기"만 보므로:

- 아주 찔끔 내려갔다가(기울기 −) 아주 찔끔 올라가도(기울기 +) 부호는 전환된다.
- **얼마나 내려왔는지(누적 낙폭)는 아무도 안 본다.** 사실상 횡보인 잔파동에서도 "바닥"을 선언한다.

→ 해법: 기울기 대신 **매도실행기(±w OCO 그리드)와 같은 사다리 논리**로 바닥을 정의한다. "간격 g%만큼 실제로 떨어질 때마다 가상 매수(홀) 1회"를 기록하고, **홀이 N번(기본 3) 쌓여야** 진짜 하락으로 인정해 실매수를 낸다. 누적 낙폭이 최소 N×g% 있어야 하므로 잔파동은 구조적으로 걸러진다.

## 2. 매도실행기 수학 확인 (질문에 대한 답)

"배율 2·간격 3이면 평단이 2%씩 깎이다가 4% 오르면 탈출?" — **거의 정확하다.** 그 조합에선 맞고, 일반식은 배율에 따라 달라진다.

- 리브래킷 1회의 평단 변화: 보유 N·평단 A에서 `floor(N×배율)`주를 `A×(1−w)`에 사니
  **새 평단 = A × (1 + m(1−w)) / (1 + m)** (m=배율, w=간격).
  - m=2, w=3% → A×(1+2×0.97)/3 = **A×0.98 → 평단이 매번 정확히 2%씩 깎인다.** ✔
- 탈출(익절)은 항상 **그 시점 평단×(1+w)**. 방금 물탄 가격(A×0.97)에서 보면
  필요 상승 = 1.03×0.98/0.97 − 1 ≈ **+4.06%**. ✔ ("4% 오르면 탈출" 직관과 일치)
- 참고로 현재 실설정(m=1, w=10%)은: 평단 매번 −5%, 물탄 가격 기준 탈출까지 약 +16.1%.

즉 "평단이 깎이는 폭"은 간격 w와 배율 m이 **함께** 정하고(m이 클수록 많이 깎임), 탈출은 언제나 평단+w%다.

## 3. 새 감지 설계 — 가상 그리드 사다리 (LadderDetector)

매도실행기의 상태기계를 **주문 없는 가상 버전**으로 감지에 쓴다. 종목 감시가 붙는 순간 가상 포지션 1개를 연 셈 치고:

```
앵커 A = 감시 시작 시점 가격 (가상 평단)
가상 매수선 = 직전 레벨 × (1−g)      ← 닿으면 홀 카운트 +1, 레벨 갱신
가상 매도선 = 직전 레벨 × (1+g)      ← 닿으면 "가상 익절" = 사다리 리셋(앵커=현재가)
```

상태기계(리샘플 청크의 마지막 가격으로 판정 — 기존 detector와 같은 입력 주기):

1. **카운트 0에서 가격이 A×(1+g) 이상** → 앵커를 현재가로 올린다(트레일링 — 상승장에서 낙폭 기준이 낡지 않게).
2. **가격이 직전 레벨×(1−g) 이하** → 홀 카운트 +1, 레벨 = 직전 레벨×(1−g). (실행기의 "매수 체결"과 동일)
3. **카운트 진행 중 가격이 직전 레벨×(1+g) 이상 반등** → 가상 익절로 보고 **사다리 전체 리셋**(앵커=현재가, 카운트 0). (실행기의 "매도 체결→SCANNING 복귀"와 동일)
4. **홀 카운트가 N(기본 3, 옵션) 도달** → **BUY 신호 발화**, 사다리 리셋. 체결 후 관리는 기존대로 매도그리드(`core/grid`)가 인계한다(GRID_EXIT 경로 그대로).

한 번에 여러 레벨을 관통하는 급락 청크는 관통한 레벨 수만큼 카운트한다(3레벨 급락 = 홀 3회).

## 4. 핵심 설계 결정 (기본값 — 이견 없으면 이대로)

| # | 결정 사항 | 채택안 |
|---|---|---|
| L1 | 사다리 수학 | **순수 가격 사다리**: 다음 매수선 = 직전 레벨×(1−g). 배율(m)은 감지에 **미적용** — 배율은 실주문 수량 개념이라 가상 감지엔 의미가 없고, 적용하면 레벨 간격이 배율 설정에 끌려다녀 튜닝이 꼬인다. 실행기의 배율은 지금처럼 매도그리드에서만 쓴다. |
| L2 | 트리거 시점 | **N번째 홀이 찍힌 청크에서 즉시 BUY** (사용자 지정 그대로). 낙하 중 진입(떨어지는 칼) 리스크는 기존 BUY 게이트(거래량 스파이크·체결강도, fail-open)를 AND로 유지해 완화한다. |
| L3 | 옵션·기본값 | 설정 탭에 2개 신설: **감지 간격 g(%) 기본 1** · **홀 횟수 N 기본 3** (→ 기본 누적 낙폭 약 3%에서 진입). ⚠ g는 매도그리드 폭(`gridWidthPct`=10)과 **별개 설정**이다 — 감지는 분 단위 잔파동, 매도그리드는 포지션 관리로 시간 스케일이 다르다. g 기본 1%는 제안값이니 확정 필요. |
| L4 | 기존 SG 감지기 처분 | 삭제하지 않는다. `feedSlot`에 감지기 선택 상수 **`LADDER_ENTRY = true`** 한 줄 롤백 스위치(GRID_EXIT와 같은 패턴). SG detector·모멘텀 확인 코드는 그대로 두고 배선만 바꾼다. |
| L5 | SELL 신호 | 새 감지기는 **BUY 전용**. 청산은 이미 매도그리드 몫(GRID_EXIT=true)이라 매도 변곡점이 필요 없다. 그리드 미주입 하네스(비그리드 폴백 경로)는 기존 SG detector를 그대로 쓴다 — 회귀 안전. |
| L6 | 리셋 시점 | BUY 발화 후·가상 익절 후·감시 해제/재부착 시 사다리 완전 리셋. 진입 후 같은 종목은 어차피 감시 제외(actives)라 이중 진입 없음. |

## 6. 하지 않는 것

- ❌ 매도그리드(`core/grid`)·주문 경로 변경 없음 — 진입 신호원만 바뀐다.
- ❌ SG detector 삭제 없음(L4 롤백 스위치).
- ❌ 반등 확인 후 진입(N홀 뒤 +g/2 회복 대기 같은 변형) — 사용자 지정은 "N홀 즉시 진입". 필요해지면 후속 옵션으로.
- ❌ 감지 배율 옵션(L1) — 감지는 간격 g·횟수 N 두 개만.
