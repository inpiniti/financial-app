# 시뮬레이션 + 주간거래 제거 plan (2026-08-08)

> 상태: **구현 완료** (tsc + vitest 497개 통과). DB 정리(§6)만 사용자 수행 대기.

## 1. 배경 / 목적

2026-08-06 시뮬레이션 plan(시뮬 모드 + SimLab 20전략 매트릭스 + Supabase 기록)을 **전부 제거**한다.
전략 연구 데이터는 더 필요 없고, 오히려 실거래 자동단타와 병행할 때 앱이 죽으려는 체감 부하의
유력 원인이다:

- **SimLab**: 매 WS 틱마다 최대 20개 가상 전략 × 동시 8에피소드 평가
- **구독 홀드**: SimLab 에피소드 종목이 단타 리스트에서 빠져도 WS 구독을 최대 8개까지 붙잡음
- **SimExchange.onTick**: 전 틱 추가 순회 + Supabase insert/AsyncStorage 큐

### 범위 확정 (사용자, 2026-08-08)

- 시뮬레이션 관련 **전부 제거** (기록·매트릭스·모드 토글·가상 체결소).
- **주간거래(KST 10~16시) 거래 기능도 같이 제거** — 주간거래는 "절대 실거래 금지" 원칙 때문에
  가상 체결소(SimExchange)를 강제로 쓰는 구조였다. SimExchange가 사라지면 주간거래는 거래 수단이
  없으므로 함께 걷어낸다. 주간거래 창에는 오토파일럿이 동작하지 않게 된다.
- DB `sim_episodes` 테이블 삭제는 사용자가 Supabase 대시보드에서 직접 수행(§6).

## 2. 삭제/유지 경계 — 왜 이 선인가

| 항목 | 처분 | 근거 |
|---|---|---|
| `simLab.ts` / `simBroker.ts` / `simEpisodeStore.ts` | **삭제** | 시뮬 전용, 다른 기능이 안 씀 |
| `daySession.ts`의 `shouldForceSimBroker` | **삭제** | 시뮬 브로커 강제 규칙 자체가 소멸 |
| `daySession.ts`의 `isDaytimeSessionOpen` | **유지** | `useQuoteFeed`(종목 상세화면)가 주간거래 창 시세 **조회**에 사용. 조회는 화면을 열었을 때만 도는 온디맨드 구독이라 부하 0 — 거래만 제거하고 보는 건 남긴다 |
| `autopilotManager`의 주간거래 R trKey 분기 | **삭제** | 오토파일럿이 주간거래 창에 거래하지 않으므로 사장 코드. **이 삭제가 곧 안전장치다**(§4) |
| `autopilotManager`의 구독 홀드(holdTick/releaseTick) | **유지(내부용)** | §5-4에서 시뮬용으로 넣었지만 실거래에도 이득이 확인됨 — 보유·진입 중 사이클이 리스트에서 탈락해도 게이지 현재가 유지 + 입양 종목 구독. SimLab 쪽 외부 훅 배선만 끊는다 |
| `core/grid`의 `roundGridPrice` | **유지** | 그리드 본체가 쓰는 함수. simLab이 재사용했을 뿐 |
| `lib/supabase` 클라이언트 · `.env` 키 | **유지** | 게이트 등 다른 기능이 사용 |
| `kis/realtimePrice`의 `buildDaytimeQuoteTrKey`, `DaytimeMarketCode` | **유지** | `useQuoteFeed`·`marketCodes.ts`(상세화면 조회)가 사용 |

## 4. 안전성 논거 — 주간거래 창에 실주문이 나갈 수 없는 이유

주간거래 plan v4의 원칙은 "런타임 토글이 아니라 **진입 경로 자체가 없는 구조**"였다. 제거 후에도
같은 성질이 유지된다:

1. 오토파일럿의 WS 구독은 D+거래소(정규장 계열)뿐 — 주간거래 체결은 R+주간시장 키로만 흐르므로
   **KST 10~16시엔 틱이 아예 안 들어온다**.
2. 진입(사다리 감지)·makeBroker 호출은 틱이 있어야만 일어난다 → 틱 없음 = 진입 없음 = 주문 없음.
3. 별도 시간 가드를 추가하지 않는다 — 가드가 필요한 상태 자체가 없다.

부수 효과: KST 10~16시에 자동 단타를 켜두면 (틱이 없어) 아무 일도 안 하고 대기만 한다. 배지 등
안내가 필요하면 추후 별건.
