# 종목 상세화면 plan

작성일: 2026-08-07
확정 사항(사용자 피드백): 탭 순서 **차트 / 댓글 / 호가**(기본 차트), 구독해제는 refcount 방식, market 누락 진입은 에러 표시, 현재가/등락률 헤더는 이번 범위에서 제외(후속 확장).

## 배경 / 문제

종목을 탭했을 때의 동작이 화면마다 전부 다르다.

| 화면 | 현재 탭 동작 |
|---|---|
| 수동 카드 (`InstanceCard`) | 카드 자체는 무반응. 하단 텍스트 버튼 3개(댓글/차트/호가)가 각각 바텀시트를 연다 |
| 자동 단타 리스트 (`AutoPilotScreen` `SlotRow`) | ActionSheet(댓글/차트/호가) → 닫힘 후 280ms 지연 → 대상 시트 오픈 (RN Modal 스태킹 프리즈 회피 핵) |
| 보유종목 (`Holdings`) | 무반응 |
| 미체결 (`PendingOrders`) | 행은 무반응, "취소하기" 버튼만 동작 |
| 순위 (`Ranking`) | AsyncStorage 프리필 저장 + Alert → 홈 배너에서 소비 |

추가 문제:

- 공용 `components/BottomSheet.tsx`는 RN `Modal` + `Animated` 자체 구현으로 **드래그 제스처가 없다**(그랩 핸들은 장식). 시트가 뜬 뒤 화면 드래그가 안 되는 현상의 원인.
- 시트 위에 시트를 띄우는 구조라 Modal 스태킹 문제를 지연(280ms)으로 우회하고 있다.

→ **바텀시트 방식을 버리고, 어디서 종목을 탭하든 "종목 상세화면" 하나로 통일한다.**

## 목표

1. 새 화면 `종목 상세` 추가: 타이틀(종목명 + 티커), 탭 **차트 / 댓글 / 호가**, 기본 탭은 차트.
2. 상단 좌측 뒤로가기, 상단 우측 `+` → 수동 카드 추가 여부 확인 후 추가.
3. 호가는 **상세화면 진입 시 구독, 이탈 시 해제** (HDFSASP0).
4. 단타(수동/자동)·보유종목·미체결·순위에서 종목 탭 → 상세화면으로 통일. (순위의 프리필 흐름은 `+` 버튼으로 대체)
5. 기존 종목별 바텀시트(ChartSheet/QuoteSheet/WatchQuoteSheet/ActionSheet + 280ms 핵) 제거.

## 설계

### 1. 라우트

- `app/stock/[ticker].tsx` (expo-router 동적 라우트, 기존 Stack에 자동 등록).
- 진입: `router.push({ pathname: '/stock/[ticker]', params: { ticker, market, name } })`
  - `market`: `NAS | NYS | AMS` — 차트 API의 `excd`, 호가 tr_key 빌드에 필요. 진입점마다 이미 보유한 값 전달.
  - `name`: 알고 있으면 전달, 없으면 타이틀에 티커만 표시.
  - **market이 없거나 매핑 불가한 진입**: 화면에 에러 상태를 표시하고 구독/조회를 시도하지 않는다 (조용한 오동작 금지).

### 2. 화면 구조

```
┌─────────────────────────────┐
│ ←  종목명 (TICKER)        + │  ← BackHeader 변형 (우측 액션 슬롯 추가)
├─────────────────────────────┤
│ [ 차트 | 댓글 | 호가 ]      │  ← SegmentedControl 재사용, 기본 차트
├─────────────────────────────┤
│                             │
│        탭 콘텐츠            │
│                             │
└─────────────────────────────┘
```

- 헤더: `components/BackHeader.tsx`에 우측 액션(옵션 prop) 추가.
- 탭: `features/inquiry/SegmentedControl` 재사용.
- `+` 버튼: 탭 시 `AddInstanceSheet`를 티커 프리필 상태로 열어 수량 입력 → `manager.add(...)`. 이미 카드에 있는 티커면 "이미 추가된 종목" 안내.
- 현재가/등락률 헤더 표시는 이번 범위에서 제외 — 구독 안 된 종목까지 관리가 복잡해지므로 후속 확장으로 미룬다.

### 3. 탭별 콘텐츠 — 기존 시트에서 패널로 추출

새 디렉토리 `features/stock/`:

| 새 컴포넌트 | 원본 | 내용 |
|---|---|---|
| `features/stock/ui/ChartPanel.tsx` | `ChartSheet.tsx` | `CandleChart`(svg 캔들) + 모드 전환(분/일/주/월, 1·3·5분) + 새로고침을 시트 껍데기 없이 추출. 화면 높이에 맞게 차트 영역 확대 |
| `features/stock/ui/CommentsPanel.tsx` | `CommentsSheet.tsx` | 토스 커뮤니티 댓글 뷰 추출 |
| `features/stock/ui/QuotePanel.tsx` | `QuoteSheet.tsx` / `WatchQuoteSheet.tsx` | 1호가(PBID1/PASK1/VBID1/VASK1) + 스프레드 + 구독 ACK 상태. 수동/자동으로 갈라져 있던 두 시트를 통합. KIS 해외 실시간 호가는 1호가만 제공 |

추출 원칙: 시트 파일은 이 plan 범위에서 삭제하고, 패널이 유일한 구현이 되게 한다.

### 4. 호가 구독 수명주기 (확정: refcount)

- 훅 `features/stock/useQuoteFeed.ts`:
  - 화면 focus 시 `HDFSCNT0`(체결가) + `HDFSASP0`(호가) 구독, blur/unmount 시 해제 (`useFocusEffect`).
  - tr_key는 `buildFreeQuoteTrKey` / `buildQuoteTrKey` 재사용. 주간거래 세션이면 daytime 빌더 — 기존 `daySession` 판정 재사용.
- **`scalperManager`에 참조 카운트 기반 보조 구독 API 추가** — `acquireFeed(trKey, trId)` / `releaseFeed(trKey, trId)`:
  - `${trId}|${trKey}` 복합 키별 refcount. 카드 구독·상세화면 구독이 모두 카운트에 합산되고, 0이 될 때만 실제 `unsubscribe`.
  - 같은 종목이 수동 카드/자동 단타 호가 예산으로 이미 구독 중일 때 상세화면 이탈이 카드 시세를 끊지 않도록 보장.
  - 기존 "같은 trKey 카드가 없을 때만 해제" 로직 흡수는 후속(이번엔 보조 API만 추가).
- 데이터 라우팅: 매니저의 보조 라우트(`setAuxRoutes`/`routeQuote`) 경로에 상세화면 리스너 등록 → `QuotePanel` 구독.
- KIS 유량: 상세화면 진입 시 +2(체결가·호가), 이탈 시 해제되므로 상시 점유 없음.

## 구현 순서

1. 패널 추출 — ChartSheet/CommentsSheet/QuoteSheet(+Watch) → `features/stock/ui/` 패널 3종.
2. 구독 refcount API — `scalperManager`에 `acquireFeed`/`releaseFeed` + 라우팅. 단위 테스트(카드 구독 중 상세 진입/이탈 시 카드 시세 유지).
3. 상세화면 — `app/stock/[ticker].tsx` + 헤더 + 탭 + `useQuoteFeed` + `+` 프리필 추가. market 누락 시 에러 화면.
4. 진입점 교체 — 5개 화면 onPress를 상세 push로 통일.
5. 정리 — 시트 4종 + ActionSheet + 280ms 핵 + 프리필 흐름 삭제.
6. 검증 — vitest 전체, 실기기: 각 진입점→상세→뒤로가기, 호가 SUBSCRIBE/UNSUBSCRIBE 확인, 카드 구독 종목 상세 진입/이탈 후 카드 시세 지속, `+` 추가 흐름, 주간거래 세션 호가.

## 리스크 / 미결

- **구독 해제 타이밍**: `useFocusEffect` 기준으로 focus/blur에 맞춰 acquire/release.
- **market 값 없는 진입점**: 미체결/보유 응답 거래소 코드 매핑(`NASD→NAS` 등 기존 `domain.ts` 재사용), 매핑 불가면 에러 표시.
- 현재가/등락률 헤더, refcount로 기존 카드 해제 로직 흡수 등은 후속.
