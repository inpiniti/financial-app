# 매도 관리 도메인 — ±10% OCO 그리드 (오토파일럿 통합)

> 작성일 2026-08-05 · 분류: **대형** (실계좌 주문 로직 신설 + 오토파일럿 상태기계 변경 + 신규 게이지 UI)
> 기준: PRD `docs/prd/2026-07-29_변곡점-단타-앱-prd.md`, 오토파일럿 `features/scalper/autopilot.ts`

## 1. 무엇을 바꾸나 (사용자 확정 + 정정 반영)

**첫 진입은 변곡점**(기존 그대로). 진입해서 포지션이 생기면, 그 뒤 관리는 **±10% OCO 지정가 그리드**가 맡는다 — 오토파일럿의 기존 "매도 변곡점 청산 + 오토런/마틴 재진입"을 **이 그리드로 교체**.

- 보유수량 N, 평단가 P 기준으로 **실제 지정가 주문 2개를 미리** 건다:
  - **매수 지정가: N주 @ P×(1−w)** (평단 −10%, 현재가 아래 → 정상 지정가로 대기)
  - **매도 지정가: N주 @ P×(1+w)** (평단 +10%, 현재가 위 → 정상 지정가로 대기)
  - w = 폭, **설정값(기본 10%)**.
- KIS는 두 지정가 모두 평범한 지정가라 거래소에 그대로 대기(스탑 주문 아님 — 즉시체결 문제 없음).
- **한쪽 체결 → 나머지 실제 취소(OCO):**
  - **매도(+10%) 체결** → 전량 정리, 포지션 0 → **변곡점 스캔(SCANNING) 복귀.**
  - **매수(−10%) 체결** → 보유 2N, 평단 재계산(P→0.95P) → **두 주문 재설정(리브래킷).**
- 정정: 사용자 최초 설명(왼쪽=매도/오른쪽=매수, 매도 −10%/매수 +10%)은 방향이 뒤집혀 있었음. **정본: 매수 −10%, 매도 +10%.** 게이지 라벨은 가격 위치에 맞춰 **왼쪽=매수(−10%), 오른쪽=매도(+10%).**

## 2. 게이지 화면 (사용자 그림)

종목명·종목코드·보유수량 헤더 + 가로 눈금 게이지:
- **중앙 = 평단가**, **왼쪽 = 매수가(P×0.9)**, **오른쪽 = 매도가(P×1.1)**.
- **현재가 = 화살표**(▼)로 게이지 위 위치 표시(범위 밖이면 끝에 고정).
- 눈금은 있어도/없어도 됨 → 간결하게 소수 눈금 + 양끝·중앙 라벨.
- react-native-svg(기설치)로 렌더. app-ui-style 준수(풀폭 패널, Ionicons).

## 3. 핵심 설계 결정 (기본값 — 이견 없으면 이대로)

| # | 결정 사항 | 채택안 (사용자 확정 2026-08-05) |
|---|---|---|
| D1 | 평단가·보유수량 출처 | **KIS 잔고 조회**(`kis/balance.ts` output1: `avg_unpr3`=평단가, `cblc_qty13`=보유수량)로 브래킷 설정 시마다 읽는다 — 가장 정확. 갓 체결돼 잔고 반영이 늦으면 짧게 재시도 후, 체결가 폴백. |
| D2 | 매수(−10%) 현금 부족 시 | 살 수 있는 **최대 수량으로 축소 발주**, 0이면 매수 다리 생략하고 **매도(익절) 다리만 유지**. |
| D3 | 매수 주문량 배율 | **설정값 `buyMultiplier`(기본 1)**. 매수 수량 = 보유수량 × 배율(1=1배, 2=2배…). 매도는 항상 보유수량 전량. |
| D4 | 마틴 배증 상한 | 세션 maxAmountUsd + 현금 부족 PAUSED가 자연 상한. 별도 횟수 상한 없음. |
| D5 | 기존 변곡점 청산과의 관계 | **그리드로 완전 교체**(사용자: "아예 바꾸고 싶다"). exitMode는 사용자 설정으로 노출 안 함 — 기존 변곡점 청산 코드는 삭제하지 않고 내부 상수(`GRID_EXIT`)로만 남겨 한 줄 롤백 가능하게. |
| D6 | 주문 방식 | 그리드 지정가는 **정확한 지정가**(P×(1−w) / P×(1+w))로 발주 — 진입 때 쓰는 "반대편 1호가 공격적 지정가"와 다른 경로. 자릿수는 formatOverseasOrderPrice. |
| D7 | 체결 확인·취소 | 기존 인프라 재사용 — nccs(TTTS3018R) 폴링 체결 감지, orderCancel(ODNO 10자리 패딩) OCO 취소. |
| D8 | 설정 항목 | 설정 탭에 **그리드 폭(%) 기본 10** + **매수 배율 기본 1** 두 개. persist. |

## 5. 하지 않는 것

- ❌ 수동 단타 카드·조회 화면은 안 건드림(오토파일럿 전용).
- ❌ 스탑/예약 주문 시도(KIS 미국 미지원 — 정상 지정가로 충분).
- ❌ 마틴 횟수 하드 상한(세션 현금 상한이 대신함 — D3).

## 6. 리스크

| 리스크 | 대응 |
|---|---|
| 마틴 배증(−10%마다 수량 2배)로 현금 소진 | D2 축소 발주 + 세션 maxAmount/PAUSED 안전망. 게이지·기록에 회차·평단 표시로 가시화 |
| 두 주문 동시 체결(급변동) | OCO 취소 실패 대비 — 체결 감지 시 반대편 취소 확인 전까지 신규 리브래킷 보류, 취소 거절이면 FAULT 동결 |
| 부분 체결 | nccs 부분 수량 반영(기존 로직) — 남은 수량 기준 재계산 |
| 기존 청산 로직과 충돌 | D4 exitMode 토글로 분리, 그리드 on일 때 변곡점 청산 경로 비활성 |
