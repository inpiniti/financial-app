# 기능: 실시간 MA5 단일 전략 고정 — 진입/청산/옵션 제거 단순화
> 작성일 · 분류: **소형** — 기존 다중 전략/옵션이 실매매 진입·물타기 누락 원인 추적을 어렵게 만들어, 단일 규칙으로 고정해 오동작 여지를 줄인다.

## 왜
- 설정의 진입 전략·진입 필터·청산 전략·포지션 옵션 선택지가 많아 실제 동작 경로가 복잡해졌다.
- 사용자 요구는 "실시간 MA5 상향 돌파 순간 매수, 보유 중 -3% 이하에서 같은 돌파 재발 시 물타기, 체결 즉시 평단+3% 매도"로 단순하다.

## 작업
| 단계 | 작업 | 사용 스킬 | 에이전트 모델 (effort) | 완료 기준 |
|---|---|---|---|---|
| 1 | 설정 저장/로딩을 실시간 MA5 단일 전략으로 고정하고 전략/옵션 선택 UI를 제거 | plan-maker | Sonnet (medium, thinking O) | 설정 화면에서 전략/옵션 선택이 사라지고 저장 후에도 realtimeMa5가 유지된다 |
| 2 | 실시간 MA5 돌파 판정을 사용자 수식(이전틱 < 현재 MA5 < 현재틱)으로 맞추고 봉당 1회 제한 제거 | plan-maker | Sonnet (medium, thinking O) | 실시간 교차가 발생한 틱마다 BUY 신호가 정상 발생한다 |
| 3 | 물타기 수량을 가용자본 기준으로 캡핑하고 체결 후 +3% 매도 선등록/정정을 유지 검증 | plan-maker | Sonnet (medium, thinking O) | 보유 중 -3% 이하 조건에서 자본 내 최대수량으로 물타기되고 매도 목표가가 즉시 갱신된다 |

## 완료 기준
- 진입/청산 전략 선택 없이 `realtimeMa5` 단일 전략으로만 동작한다.
- 매수·물타기 모두 신호 직후 발주되고, 체결 시점마다 평단 기준 +3% 매도 주문이 즉시 선등록/정정된다.
- 타입체크/테스트가 통과한다.
