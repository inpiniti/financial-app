# 기업 탭 — 뉴스 본문 기반 AI 기업 요약

> 작성일 2026-08-19 · 분류: **기능 문서** (매매 판단과 무관한 조회 기능 — 도메인 아님)
> 코드: `features/stock/companyBrief.ts`, `features/stock/ui/`, 프록시 = bitcoin-simulation 프로젝트 Vercel Edge(`/api/simple/gemini`, `/api/simple/article`)

## 1. 무엇
종목 상세의 **호가 탭을 대체**(08-19). 기업 소개·현재 상황·최근 뉴스 분석을 AI가 정리해 보여준다. 섹션: 종합 · 호재/악재 · 지켜볼 점 · 근거 기사.

## 2. 재료를 앱이 모은다
모델은 인터넷이 없고 생소한 종목을 모를 수 있어, 앱이 [1] KIS 현재가상세(시총·PER·52주·업종) [2] Yahoo 검색(정식명·섹터·헤드라인) [3] 최신 기사 N건 **본문**(`/api/simple/article`)을 프롬프트에 넣는다. 사용자는 뉴스 "목록"이 아니라 "읽고 분석한 결과"를 원한다.

## 3. 결정
- Gemini google_search 그라운딩은 무료 할당량 밖(429) → 쓰지 않음(tools 미전송).
- 모델은 gemini-3.5-flash-lite 우선, 3.1 폴백. 키는 프록시에만 있다.
- 캐시: 종목+거래일(ET) 단위 AsyncStorage — "새로고침"으로만 재호출.
- 스트리밍: 단계(시세→검색→기사 읽기→AI 정리) 표시 + JSON 조각에서 미완성 문장을 뽑아 타이핑처럼 그린다.
