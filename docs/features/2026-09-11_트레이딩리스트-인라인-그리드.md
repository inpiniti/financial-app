# 기능: 트레이딩 리스트 인라인 그리드 — 분리 패널 제거

## 왜
- 현재 화면은 `트레이딩 리스트`와 `그리드 관리`가 분리되어 있어 같은 종목을 두 번 찾아봐야 한다.
- 보유 종목은 리스트 행에서 즉시 수량/손익/그리드 위치를 함께 보는 편이 빠르다.
- 미보유 종목은 보유 데이터(수량·손익·평단)가 없으므로 해당 정보는 숨겨야 읽기 밀도가 유지된다.
