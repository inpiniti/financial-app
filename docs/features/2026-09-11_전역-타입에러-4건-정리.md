# 기능: 전역 타입에러 4건 정리 — 저장 payload/테스트 타입 동기화
> 작성일 · 분류: **소형** — 런타임 로직 변경 없이 타입 선언과 호출부 정합성만 맞추는 수정

## 왜
- `npx tsc --noEmit`에서 4건이 실패해 전체 타입 검증이 막혀 있어요.
- 4건 모두 최근 타입 확장/정제 이후 호출부 또는 테스트 fixture가 따라오지 못한 불일치예요.

## 작업
| 단계 | 작업 | 사용 스킬 | 에이전트 모델 (effort) | 완료 기준 |
|---|---|---|---|---|
| 1 | `saveAppSettings` 호출 payload에 필수 키(`realtimeMa5Config`)를 누락 없이 포함 | plan-maker | GPT-5.3-Codex (medium, thinking O) | settings 저장 호출이 `AppSettings` 타입을 만족 |
| 2 | `positionManager.test.ts` fixture를 최신 `MartingaleGridConfig`/`ModelGridConfig`에 맞춤 | plan-maker | GPT-5.3-Codex (medium, thinking O) | 테스트 fixture 객체의 초과/누락 속성 제거 |
| 3 | `ChartPanel.test.ts` trade fixture를 `buildTradeMarkers` 입력 타입에 맞춤 | plan-maker | GPT-5.3-Codex (medium, thinking O) | 초과 속성 에러 제거 |
| 4 | 타입체크 재실행 | plan-maker | GPT-5.3-Codex (medium, thinking O) | `npx tsc --noEmit` 통과 |

## 완료 기준
- 전역 타입에러 4건이 모두 사라진다.
- 실제 매매 로직 동작은 변경하지 않는다.
