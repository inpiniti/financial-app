# 도움말 — 사용 설명서 + 앱 사용법 챗봇

> 작성일 2026-08-21 · 분류: **기능 문서** (매매 판단과 무관한 조회 기능 — 도메인 아님)
> 코드: `features/help/appManual.ts`(설명서) · `helpChat.ts`(프롬프트·왕복 루프) · `tools.ts`(읽기 전용 도구) · `webSearch.ts`(뉴스 검색) · `ui/HelpChat.tsx` · `app/help.tsx`
> 프록시: bitcoin-simulation `api/simple/gemini.js`(함수 호출 통과), `api/simple/article`(Yahoo 본문)
> 진입: 홈 상단바 **말풍선**(검색 돋보기 옆)

## 1. 무엇
앱 사용법을 물어보면 답하는 챗봇. 근거가 셋이다 — **설명서**(앱 동작), **앱 데이터**(도구로 조회), **인터넷 뉴스**(검색). 그 밖의 일반 지식은 모델이 아는 대로 답한다.
"설명서 전체 읽기"로 원문도 그대로 볼 수 있다 — AI가 실패해도 도움말은 산다.

## 2. 구조
```
systemInstruction = 답변 규칙 + APP_MANUAL + 사용자의 현재 설정·상태
contents          = 최근 8턴 대화
tools             = HELP_TOOL_DECLARATIONS (읽기 전용 9개)
        ↓ /api/simple/gemini (스트리밍)
모델이 도구를 부르면 → [[FN_CALL]]{파트}[[/FN_CALL]] 마커로 도착
        ↓ runHelpTool 실행
functionResponse를 붙여 재요청 (최대 MAX_TOOL_ROUNDS=4 왕복) → 텍스트 답변
```

## 3. 도구 (전부 읽기 전용)
`getAutopilotStatus` · `getWatchlist`(추세 4선 방향 포함) · `getHoldings` · `getPendingOrders` · `getTodayTrades` · `getQuote` · `searchStock` · `getStockNews`(Yahoo 기사 **본문**) · `searchWeb`(Google 뉴스).

**불변식(사용자 확정)**: 주문·정정·취소·시작·정지·설정 저장은 도구로 만들지 않는다. AI 판단이 실계좌를 건드리는 경로를 아예 두지 않는다. `tools.test.ts`가 이름 규칙(`get*`/`search*`)으로 강제한다. 쓰기가 필요하면 도구가 아니라 "어느 화면 어느 버튼"으로 안내한다.

## 4. 검색 경로를 이렇게 고른 이유 (2026-08-21 실측)
| 후보 | 결과 |
|---|---|
| Gemini `google_search` 그라운딩 | **429**(무료 할당량 밖). 2026-08-19 결론 그대로 |
| DuckDuckGo html/lite, SearXNG 공개 인스턴스 | 봇 차단(캡차) — 못 믿는다 |
| **Google 뉴스 RSS** | 키 없이 200, 한국어·영어 최신 결과 → **채택** |

한계: RSS의 링크는 `news.google.com` 리다이렉트인데 서버 리다이렉트가 아니라 JS 페이지라 **본문을 못 끌어온다**. 그래서 `searchWeb`은 제목·언론사·날짜까지고, 결과 객체에 그 한계를 같이 실어 보낸다(모델이 본문을 지어내지 않게). 종목 기사 **본문**이 필요하면 `getStockNews`(Yahoo, 기업 탭과 같은 경로)를 쓴다.

## 5. 프록시에서 배운 것
- `sseToTextStream`이 `parts[0].text`만 보고 있었다 → **파트 전부 순회**로 고쳤다(두 번째 파트부터 조용히 버려지던 버그 포함). `thought` 파트는 사용자에게 흘리지 않는다.
- functionCall 파트는 **통째로** 마커에 실어야 한다. Gemini 3.x는 다음 턴에 `thoughtSignature`가 빠지면 400("Function call is missing a thought_signature")을 낸다 — functionCall만 뽑아 보내면 후속 요청이 전부 실패한다.
- `functionResponse.response`는 객체여야 한다(배열·원시값 거절) → 아니면 `{ value }`로 감싼다.

## 6. 답변 규칙
- 앱 동작(규칙값·설정·화면)은 설명서와 상태 블록만 근거로. 기억으로 말하지 않는다.
- 사용자 데이터·시점을 타는 숫자는 추측 금지, 도구로 확인.
- 일반 지식은 아는 대로 답하되 불확실하면 불확실하다고 말한다.
- 종목 추천·주가 예측·매매 조언·수익 보장 금지.
- 서식 금지(표·코드블록·`#`·`**`) — 화면이 RN `<Text>`라 별표가 글자로 보인다. 프롬프트로 막고 `stripMarkdown`이 한 번 더 걷어낸다.

## 7. 아직 안 한 것
- **일반 웹페이지 본문 읽기** — `/api/simple/article`이 finance.yahoo.com 전용이다. 아무 https나 읽게 넓히면 오픈 프록시(SSRF)가 되므로 보류 상태다(2026-08-21 판단 보류).
- 대화 저장 — 화면을 나가면 사라진다.
- 도구 호출 비용·할당량 모니터링. 도구 왕복은 요청이 2배가 된다.
