# 도움말 — 사용 설명서 + 앱 사용법 챗봇

> 작성일 2026-08-21 · 분류: **기능 문서** (매매 판단과 무관한 조회 기능 — 도메인 아님)
> 코드: `features/help/appManual.ts`(설명서) · `helpChat.ts`(프롬프트·왕복 루프) · `tools.ts`(읽기 전용 도구) · `webSearch.ts`(뉴스·웹 검색) · `ui/HelpChat.tsx` · `app/help.tsx`
> 프록시: bitcoin-simulation `api/simple/gemini.js`(함수 호출 통과), `api/simple/search`(Tavily), `api/simple/article`(Yahoo 본문)
> 진입: 홈 상단바 **말풍선**(검색 돋보기 옆)

## 1. 무엇
앱 사용법을 물어보면 답하는 챗봇. 근거가 셋이다 — **설명서**(앱 동작), **앱 데이터**(도구로 조회), **인터넷 검색**. 그 밖의 일반 지식은 모델이 아는 대로 답한다.
"설명서 전체 읽기"로 원문도 그대로 볼 수 있다 — AI가 실패해도 도움말은 산다.

## 2. 구조
```
systemInstruction = 답변 규칙 + APP_MANUAL + 사용자의 현재 설정·상태
contents          = 최근 8턴 대화
tools             = HELP_TOOL_DECLARATIONS (읽기 전용 12개)
        ↓ /api/simple/gemini (스트리밍)
모델이 도구를 부르면 → [[FN_CALL]]{파트}[[/FN_CALL]] 마커로 도착
        ↓ runHelpTool 실행
functionResponse를 붙여 재요청 (최대 MAX_TOOL_ROUNDS=4 왕복) → 텍스트 답변
```

## 3. 도구 (전부 읽기 전용)
`getAutopilotStatus` · `getWatchlist`(추세 4선 방향 포함) · `getHoldings` · `getPendingOrders` · `getTodayTrades` · `getQuote` · `searchStock` · `getStockNews`(Yahoo 기사 **본문**) · `searchNews` · `searchWeb` · `getAccountBinding` · `getRawApiResponse`

**불변식(사용자 확정)**: 주문·정정·취소·시작·정지·설정 저장은 도구로 만들지 않는다. AI 판단이 실계좌를 건드리는 경로를 아예 두지 않는다. `tools.test.ts`가 이름 규칙(`get*`/`search*`)으로 강제한다. 쓰기가 필요하면 도구가 아니라 "어느 화면 어느 버튼"으로 안내한다.

**진단 도구 둘**(2026-08-21 추가 — 계좌 바인딩이 이상하다는 제보):
- `getAccountBinding` — 로그인(게이트) 계좌와 KIS 설정 계좌가 **같은지**(숫자만 비교 — 게이트는 `12345678-01`, 설정은 8+2로 쪼개 저장돼 표기가 다르다), 앱키·시크릿 유무, 거래 환경. 계좌번호는 앞 4자리·뒤 2자리만 남기고 가린다 — 외부 프록시로 전체가 나가지 않게.
- `getRawApiResponse` — KIS **원본 응답 JSON**을 가공 없이(`balance` · `unfilled` · `priceDetail`). 6,000자를 넘으면 잘라내고 잘렸다고 알린다. 프롬프트에도 "원본을 보여 달라고 하면 요약하지 말고 그대로 적어라"를 넣었다 — 요약해 버리면 디버깅이 안 된다.

## 4. 검색은 두 갈래
| 도구 | 원천 | 한도 | 주는 것 |
|---|---|---|---|
| `searchNews` | Google 뉴스 RSS | 무제한(무키) | 제목·언론사·날짜 |
| `searchWeb` | Tavily(프록시 `/api/simple/search`) | 월 1,000회 | 제목·주소·**본문 발췌**·요약 |

뉴스 질문은 RSS로 받아 Tavily 크레딧을 아낀다(도구 설명에 그렇게 적어 모델이 고르게 한다).

Tavily를 고른 이유 — 무키 일반 검색은 전부 막혀 있다(2026-08-21 실측): DuckDuckGo html/lite·SearXNG 공개 인스턴스는 봇 차단(캡차·403·429), **Bing RSS(`format=rss`)는 200에 10건이 오지만 질의와 무관한 결과**(“moving average crossover”에 Copilot·Reddit), Mojeek HTML은 자기 사이트 링크뿐, Marginalia API는 응답 없음, Gemini `google_search` 그라운딩은 429. Tavily는 **본문 발췌까지** 주기 때문에 임의 URL 페처(오픈 프록시가 되는 그것)를 따로 만들 필요가 없다.

키는 서버 환경변수 `TAVILY_API_KEY` — 없으면 프록시가 503과 함께 "검색 키가 아직 설정되지 않았어요"를 돌려주고, 그 문구가 챗봇 답변으로 그대로 나온다. Google 뉴스 RSS는 키와 무관하게 계속 동작한다.

## 5. 프록시에서 배운 것
- `sseToTextStream`이 `parts[0].text`만 보고 있었다 → **파트 전부 순회**로 고쳤다(두 번째 파트부터 조용히 버려지던 버그 포함). `thought` 파트는 사용자에게 흘리지 않는다.
- functionCall 파트는 **통째로** 마커에 실어야 한다. Gemini 3.x는 다음 턴에 `thoughtSignature`가 빠지면 400("Function call is missing a thought_signature")을 낸다 — functionCall만 뽑아 보내면 후속 요청이 전부 실패한다.
- `functionResponse.response`는 객체여야 한다(배열·원시값 거절) → 아니면 `{ value }`로 감싼다.

## 6. 답변 규칙
- 앱 동작(규칙값·설정·화면)은 설명서와 상태 블록만 근거로. 기억으로 말하지 않는다.
- 사용자 데이터·시점을 타는 숫자는 추측 금지, 도구로 확인.
- 일반 지식은 아는 대로 답하되 불확실하면 불확실하다고 말한다.
- 종목 추천·주가 예측·매매 조언·수익 보장 금지.
- 서식 금지(표·코드블록·`#`·`**`) — 화면이 RN `<Text>`라 별표가 글자로 보인다. 프롬프트로 막고 `stripMarkdown`이 한 번 더 걷어낸다. **예외**: 원본·JSON을 보여 달라고 하면 그대로 적는다(코드펜스 줄만 걷어내고 안쪽은 남긴다).

## 7. 아직 안 한 것
- **임의 URL 본문 읽기** — `/api/simple/article`은 finance.yahoo.com 전용 그대로 둔다. Tavily가 본문 발췌를 주므로 오픈 프록시(SSRF)를 만들 이유가 없어졌다.
- 대화 저장 — 화면을 나가면 사라진다.
- 도구 호출 비용·할당량 모니터링. 도구 왕복은 Gemini 요청이 2배가 되고, `searchWeb`은 Tavily 크레딧을 쓴다.
