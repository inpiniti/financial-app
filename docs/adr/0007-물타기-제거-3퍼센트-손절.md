# 물타기를 제거하고 ±3% 손절/익절로 바꾼다 (ADR 0006 시험 모드의 청산 규칙 개정, 데이터 반대에도 사용자 결정)

ADR 0006(2026-08-27)의 배수 물타기 시험을 닷새 돌린 실거래 분석(`docs/분석/2026-09-01_물타기-vs-손절-비교.md`, 55건)은 **물타기가 이 기간 수익의 대부분을 만들었다**고 나왔다 — 물타기 발생 12건 실제 +$13.37 vs "물타기 없음 + −3% 손절" 가정 −$0.54(전체 +$16.73 vs +$2.82). 손절선을 −4%/−5%로 늦춰도 결과는 같다(물타기 발생 건의 최소 낙폭 추정이 9/11건에서 −7.5%~−26% — 어디에 둬도 손절되고, 손절당 손실만 커진다).

그럼에도 사용자는 전환을 결정했다: "그냥 −3%로 해서 진행해줘. 한번 내가 직접 눈으로 보는게 나을듯." 근거는 수익이 아니라 **꼬리 위험의 직접 관측** — 물타기는 AIM 3,825주 · $1,037(계좌의 ~15%)까지 불었고, 한 번이라도 회복 못 하면 기간 수익 전체를 되돌릴 수 있는 구조다(이번 표본에는 그 꼬리가 아직 안 나왔을 뿐). 절충안(물타기 유지 + 종목당 투입 상한)은 권고로 남긴다 — 재검토 시 이 문서부터.

**Decision**: `core/martingale`의 청산·세션 규칙을 바꾼다 —

1. **물타기 제거**: 5선 변곡 BUY(kind='add') 신호·배수 매수·익절 사다리(+3/+2/+1)·간격 5분 전부 삭제. `MartingaleRule.decide`는 항상 null.
2. **손절 도입**: 평단 −3% 도달 시 전량 매도(STOP_LOSS, 틱 판정). 손절 매도는 취소선 없이 무조건 체결까지(익절만 목표가 아래로 내려가면 접는다).
3. **익절 +3% 고정**: 평단 +3% 도달 시 전량 매도(TAKE_PROFIT) — 사다리 없이 단일값.
4. **세션 제한**: 진입은 프리·정규·애프터(04:00~19:55 ET)만 — 주간거래(20:00~04:00 ET) 진입 제외(2026-08-28의 "모든 세션 진입" 개정). 8/18~8/31 표본에서 주간거래 진입은 2건 +$0.15로 성과 기여가 없었다.
5. **유지**: 진입 규칙(정배열·4선 상승·5선 위, 이벤트 재진입), 매수 매도1호가 추종, 19:55 ET 마감 청산, `MARTINGALE_MODE` 스위치, strategy 기록 이름 `martingale`(기록 연속성).

**Considered**: 물타기 유지 + 종목당 투입 상한 $100~200(분석과 가장 정합, 권장했음) — 사용자가 손절 방식을 직접 관측하기로 결정. 손절 −4%/−5% — 낙폭 분포상 −3%와 사실상 동일하고 손실만 커져 배제. ADR 0001의 고정 수량 물타기 복귀 — 이 모드의 목적(단순 규칙 관측)과 안 맞아 배제.

**Consequences**: 기대 손익은 표본 기준 하락한다(위 수치). 대신 종목당 최대 손실이 최초 진입금액의 ~3%+슬리피지로 캡되고, 저가 동전주의 장중 5%+ 낙폭이 일상이라 **STOP_LOSS 빈도가 높을 것** — 관측 포인트는 ① 손절 건수/일 ② 손절 체결 슬리피지(exit_snapshot.line 대비) ③ 손절 뒤 재진입(이벤트 봉) 빈도 ④ +3% 도달률. ADR 0006의 물타기 규칙 서술은 이 ADR로 대체된다(ADR 0001은 다른 모드에 그대로 유효).
