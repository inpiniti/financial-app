# 서킷 종목은 첫 정지·하킷 1회에 팔지 않고, 하킷 2연속부터 정지 중 지정가로 판다

LULD 정지 종목(AIXC 08-18: 정지 24회, 거래 가능 창 1~2분)은 분봉이 안 쌓여 추세 규칙(ma5 꺾임)이 시간축에서 작동하지 않는다. 실측에서 상승 국면에도 하킷이 한 번씩 끼어들었고(1.69, 2.59) **하킷 1회는 꺾임 신호가 아니었으며** 2연속(2.99↓, 2.45↓)부터 내리막이 이어졌다. 그래서 상킷은 홀드, 하킷 2연속(또는 손절선)에서만 **정지 중 지정가**로 재개 단일가를 소화하고, 서킷 상태에선 ma5 청산을 무시한다. 첫 정지 매도는 금지.

**Considered**: 첫 정지 즉시 매도(고점 놓침) · 하킷 1회 매도(상승 국면 오판) · 2연속(선택) · 호가 도메인 신설(WS 예산·복잡도 대비 이득 불명 — 안 만듦).

**Consequences**: 지금은 이벤트만 기록(`CIRCUIT_MODE=false`). 정지 중 주문 접수 여부·정지 중 WS 동작·문턱은 첫 실사용 이벤트로 확인한 뒤 켠다. 앱 밖 수동 청산은 `MANUAL` 사유로 정산.
