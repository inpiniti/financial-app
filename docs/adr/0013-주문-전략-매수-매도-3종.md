# 주문 전략 — 매수·매도 각각 "1호가 크로스 / 현재가 추종 / 현재가 + 시간 취소" 3종을 설정으로

사용자 요구(2026-09-03): "매도·매수 둘 다 — ① 1호가로 빠르게 주문, 미체결이면 틱 수신 시 호가가 바뀐 경우 수정 ② 현재가로 지정, 미체결이면 틱마다 현재가가 바뀐 경우 수정 ③ 현재가로 지정, 미체결이고 일정 시간이 지나면 자동 취소(시간은 옵션)."

배경: 2026-09-03 이전엔 발주가·정정이 엔진별로 굳어 있었다 — 매수는 물타기 모드 매도1호가 추종(2026-08-28), 기울기 모드 현재가+취소(같은 날 사용자 정정), 모델 모드 매도1호가 고정; 매도는 전 모드 매수1호가 크로스+추격(2026-09-01 슬리피지 수정). 이 결정으로 전부 설정 하나로 옮긴다.

**Decision**: `features/scalper/orderStrategy.ts` — `OrderPricing = 'quote' | 'lastChase' | 'lastCancel'`, `OrderStrategy = { buy, sell, buyCancelAfterMs, sellCancelAfterMs }`. 설정(`appSettings.buyStrategy·sellStrategy·buyCancelAfterSec·sellCancelAfterSec`)이 정본, 기본 `quote/quote`(옛 동작). **실행 중 즉시 반영**(`AutoPilot.applySettings` → `applyOrderStrategy`, 포지션 관리자는 틱마다 getter로 읽음) — 이미 걸린 주문도 다음 틱부터 새 전략.

| | quote | lastChase | lastCancel |
|---|---|---|---|
| 발주가 | 반대편 1호가(매수 ask1·매도 bid1, 신선할 때) | 현재가(마지막 체결가) | 현재가 |
| 미체결 | 1호가가 바뀌면 그 호가로 정정 | 틱마다 현재가가 바뀌면 정정 | 정정 없음 |
| 취소 | 없음(체결까지) | 없음 | `cancelAfterMs` 뒤 잔량 취소 — 매수는 다음 신호 대기(`tryAbandonBuy`), 매도는 폴이 취소를 확정하면 다음 틱 판정이 새 현재가로 다시 낸다(`Execution.cancel` 공개) |

배선:
- 매수 진입(AutoPilot): `OrderPortAdapter.buyAtLastPrice = buy !== 'quote'`; 리프라이스 틱에서 quote→`repriceBuy`(ask1), lastChase→`repriceBuyToLast`(러너가 틱마다 `setLimitPrice`), lastCancel→정정 없음 + `tryAbandonBuy`(전략이 주입됐으면 lastCancel일 때만·그 시간). 옛 `buyCancelAfterMs` 단독 설정은 전략 미주입(옛 하네스)일 때만 유효.
- 매도·물타기 매수(RulePositionManager): `exitOrderPrice`/`buyOrderPrice`가 quote일 때만 1호가 크로스, `driveExec`가 전략별 추격/시간 취소. lastCancel 중에도 취소선(`shouldAbort`)은 접수가로 계속 본다.
- 설정 화면 "주문" 패널: 매수·매도 카드 3장씩 + lastCancel일 때만 취소 대기 슬라이더(초). 매뉴얼 §7·챗봇 설정 설명에 전략 표기.

**Considered**: 전략을 매수·매도 공통 하나로 — 사용자가 "둘 다 각각"으로 요구. 매도 lastCancel 뒤 재발주를 즉시(취소 확정 전) — 잔량 이중 발주 위험이라 폴 확정 후 다음 틱 판정에 맡김. 취소 시간을 전략과 무관하게 항상 적용 — 사용자 정의(①②는 취소 없음)와 어긋나 배제(옛 하네스 호환만 남김).

**Consequences**: 매수 lastCancel은 미체결 포기가 잦아질 수 있고(취소 3연속 → 1분 쿨다운 그대로), 매도 lastCancel은 급락 중 "취소 → 재발주"를 반복하며 체결가가 계단식으로 내려갈 수 있다(취소 대기가 길수록). 슬리피지 실측(docs/분석 2026-08-27·09-01)은 quote 기준이라 다른 전략의 실측은 새로 필요 — 관측 포인트: 전략별 진입 미체결률·평균 대기·청산 슬리피지.
