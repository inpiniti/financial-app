# 매도 리프라이스는 매수1호가만 추종하고 시간이 지나도 가격을 양보하지 않는다

매도 지정가가 안 붙어 씹히는 문제를 "매수1호가가 바뀔 때마다 정정"으로 해결하면서, 오래 안 붙으면 더 낮게 내리는 시간 에스컬레이션은 넣지 않기로 했다 — 하락장에서 계속 양보하는 매도는 사실상 시장가 손절이고, 사용자 철학(고정 손절 없음, 하락 방어는 신호 청산이 맡음)과 충돌한다. `decideReprice`의 입력에 **경과 시간이 아예 없어** 타입 수준에서 에스컬레이션을 짤 수 없게 했다.

**Consequences**: 이 정책을 바꾸려면 시그니처를 바꿔야 하고 그 순간 리뷰에 걸린다(의도된 마찰). 정정은 절사 후 가격끼리 비교해야 한다(raw 비교 시 정정 폭주).
