# 엔진 옵션 — 엔진(택1)과 별개로 중복 선택하는 진입 필터·물타기, 세 엔진 공통

사용자 요구(2026-09-03): "설정 엔진모드에 중복으로 옵션을 넣을 수 있는 게 있으면 좋겠다. 옵션은 정배열, 5선만 상승, 5·20·60·120 모두 상승, (k−1)배 물타기. 엔진 자체는 5선돌파, 예측모델, 기울기 3개 중 하나만 선택." 적용 범위를 물었고 **세 엔진 모두**로 확정.

**Decision**: 설정에 `engineOptions`(4개 불리언)를 추가하고 엔진과 직교하게 배선한다.

1. **진입 필터** `ordered`(정배열 ma5>ma20>ma60>ma120) · `ma5Up`(5선 상승) · `allUp`(4선 모두 상승) — 1분봉 4선(SMA) 기준, 체크한 것끼리 AND, 봉 부족 등 판정 불가는 미충족(fail-closed). `core/martingale.EntryFilters`·`entryFiltersPass`.
   - 5선 돌파 엔진: 돌파 봉(`crossUp`)에 AND → `entry`. 기본값(5선 상승만)이 2026-09-02 규칙과 동일해 동작이 바뀌지 않는다.
   - 모델·기울기 엔진: BUY 신호를 낼 때 게이트(`FeedSlot.passesEntryFilterNow` — 진행 중 1분봉을 현재가로 넣은 4선 상태). 필터가 하나라도 켜지면 그 슬롯도 1분봉을 쌓고 시드(워밍업)를 받는다. 옵션 미체크면 봉을 쌓지 않는다(옛 동작).
2. **(k−1)배 물타기** `martingale` — 보유 중 그 엔진의 BUY 신호에서 현재가 ≤ 평단×(1−3%)면 낙폭 k%(내림, 3~50)에 현재 보유량 ×(k−1)(ADR 0010 규약 그대로). 5선 돌파 엔진은 `MartingaleRule.averagingDown` 스위치, 모델·기울기는 `AveragingDownRule` 데코레이터(안쪽 규칙이 BUY에 null이면 물타기 결정; 나머지는 위임). 모델은 서킷 데코레이터 **안쪽**에 둔다(정지 중엔 서킷이 신호를 잡는다). 물타기 체결 뒤 새 평단은 `setPosition`으로 안쪽 규칙에 들어가 익절·손절선이 새 평단을 따른다.
3. **기본값** `{ ordered:false, ma5Up:true, allUp:false, martingale:true }` — 5선 돌파 엔진의 현행 동작 보존. 저장값이 없거나 손상이면 키별로 기본값. 반영은 엔진 모드와 같은 규약(앱 재시작, ADR 0008).
4. **화면·문구** — 설정 엔진 모드 패널 아래 체크박스 4개(엔진 카드 제목 "5선 돌파"로 정리), 5선 돌파 고정값 패널이 옵션을 반영, 트레이딩 리스트 한 줄에 "5선 돌파했지만 옵션 미충족(정배열 아님)"/"옵션 조건 미충족", 요약 줄·매뉴얼 §7·챗봇 설정 설명에 옵션 표기.

**Considered**: 옵션을 5선 돌파 엔진에만 — 사용자가 세 엔진 모두로 확정. 물타기를 모델 라벨(±3% 대칭)과 충돌한다고 막기 — 사용자 선택에 맡기되 armText·화면에 명시. 필터 판정 불가를 통과로(fail-open) — 새 종목이 122봉 전에 필터 없이 진입하게 되어 배제.

**Consequences**: 모델·기울기 엔진에 필터를 켜면 진입 빈도가 줄고(특히 정배열·4선 상승은 저가 급등주에서 드묾) 슬롯마다 1분봉 시드 호출이 늘어난다. 모델 엔진 + 물타기는 학습 라벨(한 번 사고 ±3%)과 다른 기하가 되어 검증 숫자가 근거가 아니게 된다 — 관측 포인트: 옵션 조합별 진입 건수·승률·최대 투입. 옵션 조합이 늘었으므로 분석 시 `engineOptions`를 기록 조건에 함께 적는다(거래 기록엔 아직 옵션이 저장되지 않는다 — 필요해지면 strategy 태그 확장).
