# 엔진 모드 셋째 — 기울기 단타 (기울기/10초 ≥ +1% 진입, < +1% 즉시 전량 매도, 그 외 조건 없음)

사용자 요구(2026-09-02): "트레이딩 리스트에 보면 기울기라는걸 감지하고 있음. 기울기가 1% 이상 되면 매수하고, 그리드에서 다른거 1도 안보고 기울기가 1% 이하로 내려가면 그냥 가차없이 매도임. −3%이니 +3%니, 물타기니 아무런 조건이 없음. 대신 기울기를 정말 0.1초의 오차없이 아주 빠르게 계산하는 능력이 중요할듯."

**Decision**: 설정 > 엔진 모드에 `slope`("기울기 단타")를 추가한다(`SLOPE_MODE` 킬스위치 AND `slope` 주입, 다른 모든 모드보다 우선).

1. **지표** — 기존 표시 지표 "기울기/10초"(`SlopeMeter` v2: 직전 10초 봉 평균 대비 현재 10초 봉 평균의 %, `docs/domain/기울기`) 그대로. 봉·이동평균·모델은 쓰지 않는다. 이 ADR로 기울기/10초는 "표시 전용"에서 벗어나 매매 판정에 쓰인다.
2. **신호** — 슬롯이 **틱마다**(스로틀 없음) 기울기를 재서 문턱 **전환**에서만 낸다: 아래·모름 → ≥ +1% 이면 BUY, 이상 → < +1% 또는 null 이면 SELL (`core/slope.evaluateSlopeTransition`). 같은 상태 반복은 조용하다(부착 순간 "이미 위"인 종목은 가짜 BUY 없음).
3. **진입** — 미보유 BUY는 오토파일럿의 공통 게이트(매수 후보 안·최소 속도·현금·자리·쿨다운)만 거친다. 세션·시간대 조건 없음, 추격 게이트(+1%) 없음, 매수 미체결은 매도1호가 추종(물타기 모드와 동일).
4. **청산** — 보유 중 SELL 신호 또는 틱 판정(`SlopeRule.onPrice`: 기울기 < +1% 또는 null)이면 **손익 무관 즉시 전량 매도**(사유 SELL_SIGNAL). 익절·손절·물타기·시간·마감 청산 없음. 취소선 없음 — 체결까지 매수1호가 추종.
5. **속도** — 틱 판정에 더해, 보유 중엔 오토파일럿 리프라이스 타이머를 `SLOPE_EXIT_TICK_MS`=**100ms**로 돌려(`RulePositionManager.tick` → `onPrice`) 틱 사이의 창 슬라이딩(직전 봉이 빠져나가며 기울기가 저절로 내려가는 것)까지 잰다. 계산은 20초치 틱 선형 스캔이라 종목당 10회/초는 가볍다.
6. **null 처리** — 기울기 공급이 **없으면**(슬롯 없는 입양 포지션) 틱 판정을 하지 않는다(모르는 값으로 남의 보유를 던지지 않게). 공급이 있는데 null(10초 봉이 비었다 = 체결 끊김)이면 "기울기가 없다"로 보고 판다 — 모멘텀 매매에서 체결 정지는 곧 이유 소멸.
7. **유지** — 다른 두 모드(5선 물타기 단타·모델)는 그대로. 거래 기록 strategy 태그 `slope` 추가. 설정 반영은 앱 재시작(ADR 0008 규약).

**Considered**: 청산도 신호 경로만(틱 판정 없음) — 틱이 끊긴 사이 창이 미끄러져 기울기가 내려가도 못 팔아 배제. 100ms 대신 매 틱만 — 저유동 종목에서 초 단위 공백이 생겨 배제. null을 "판정 불가 → 보유"로 — 사용자 규칙("가차없이")과 어긋나고, 체결 없는 종목을 붙들 이유가 없어 배제(단 공급 자체가 없는 입양은 예외). 진입·청산 문턱 분리(히스테리시스) — 규칙에 없어 같은 값(1%)으로 두되 `SlopeConfig`에 둘을 분리해 두었다(중간 띠는 상태 유지).

**Consequences**: 기울기 +1%/10초는 오래 유지되지 않으므로 보유가 수십 초 단위로 매우 짧고 거래가 잦다 — **슬리피지(진입 매도1호가 추종 + 청산 매수1호가 크로스)가 성과를 결정**한다. 백테스트·실거래 근거 없음(신규). 관측 포인트: ① 거래 건수/일·평균 보유 시간 ② 건당 슬리피지(entry/exit snapshot 대비) ③ null 청산 비율(체결 끊김으로 판 건) ④ 진입 직후(10초 내) 청산 비율 — 문턱을 올리거나 히스테리시스를 둘 근거. 표본이 쌓이면 `docs/분석/`에 기록.
