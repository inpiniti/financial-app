# 배수 물타기를 **시험 모드**로 다시 켠다 (ADR 0001의 예외, 소액 실거래 검증 목적)

ADR 0001(2026-08-15)은 배수 물타기(마틴게일)를 올인 경험으로 금지하고 고정 수량만 허용했다. 2026-08-27 financial-analyze 연구(`docs/analysis/2026-08-27_물타기-변형.md`, 869거래일)에서 배수 물타기는 **무한 자본이면 승률 72~98%지만 자본 꼬리가 수천~수억 배**이고, 트리거를 엄격히 해도(변곡·전이평·확률·상위 1% 신호) 총손익이 나빠지며, 꼬리를 자르는 장치는 익절 사다리(+3/+2/+1)와 자본 상한뿐이었다. 상한 30단위에서 백테스트는 흑자일 90%·하루 최악 −15단위였으나, 슬리피지 0·1분봉 고가 터치 체결 가정이라 실거래 기대치는 미지수(실측 슬리피지 0.8~1.9%p면 음수 유력).

사용자는 "돈을 벌기 위해서가 아니라 실거래로 검증하기 위해" 소액 시험을 결정했고, **자본·횟수 상한과 킬 스위치는 두지 않기로** 했다(현금 부족이면 그 물타기만 건너뛴다).

**Decision**: `core/martingale` + `MARTINGALE_MODE`(`features/scalper/martingaleMode.ts`) 시험 모드를 추가한다. 규칙 — 1분봉 정배열·5선 상향 돌파 진입 / 익절 평단 +3%(0회)·+2%(1회)·+1%(2회 이상) / 5선 변곡에서 평단 대비 −k%(k≥3)면 보유량의 (k−1)배 물타기, 간격 5분 / 손절·트레일 없음 / 15:55 ET 전량 청산(오버나이트 금지). 켜면 모델·추세보다 우선하고, `MARTINGALE_MODE=false`로 한 줄 롤백된다. ADR 0001은 다른 모드(조건부 그리드·OCO)에 그대로 유효하다.

**Considered**: 자본 상한 30~100단위(백테스트 권고) — 사용자가 시험 목적으로 배제. 모델 진입 + 물타기 — 상한에서 이익 −54~−71%, 배제. 익절 지정가 상시 거치(OCO) — 배선 단순화를 위해 틱 판정 + 현재가 추격으로 시작(목표가 아래로 내려가면 추격 취소).

**Consequences**: 한 종목에 계좌 현금 전부가 들어갈 수 있다(현금 부족 외 브레이크 없음). 시험 프로토콜: 1단위 ≤ $100, 동시 보유 1개, 2주. 판정 기준은 `financial-analyze/docs/analysis/2026-08-27_앱-적용-계획.md` §3 — 물탄 사이클 익절률·하루 최악·가격대별 슬리피지(진입가/물타기 체결가/익절 목표 대비 체결가 = `exitSnapshot.line`). 기준 미달이면 모드 폐기.
