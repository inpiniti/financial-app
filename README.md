# 변곡점 단타 Expo 앱

한국투자증권(KIS) Open API로 실시간 체결가를 받아, Savitzky-Golay 필터의 1차/2차 미분으로 **변곡점(기울기 부호 전환)**을 감지해 자동 매수·청산하는 React Native(Expo) 단독 앱입니다.

## ⚠️ 운영 전제 (필독)

1. **실계좌 소액·최소 수량 전제**: 손절·익절 없이 변곡점 신호로만 청산하므로, 실전 투입 시 소액 및 최소 수량으로 시작해야 합니다.
2. **매매 중 화면 항시 켜둠 (백그라운드 미지원)**: Expo는 백그라운드 실행을 지원하지 않습니다. 앱 구동 중 화면을 꺼지지 않도록 유지해야 하며, keep-awake는 기본 활성화되어 있습니다.
3. **KIS 문서가 스펙**: `docs/koreainvestment/README.md`의 공식 KIS API 문서가 이 앱의 정본 스펙입니다. 앱 동작은 KIS 문서를 따릅니다.

## 시작하기

### 1단계: 설치 및 환경 변수 설정

```bash
npm install
```

`.env` 파일을 `.env.example`을 참고해 작성합니다:

```bash
# .env 예시
EXPO_PUBLIC_SUPABASE_URL=https://xxx.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=eyJxxxxx
```

Supabase 설정:
1. [Supabase 대시보드](https://supabase.com)에서 프로젝트 생성 (또는 기존 프로젝트 사용)
2. **Project Settings → API** 에서 **Project URL** 과 **anon public key** 복사
3. `.env` 파일에 붙여넣기
4. Supabase **SQL Editor** 에서 `supabase/migrations/0001_approved_users.sql` 전체 실행 (approved_users 테이블 생성)
5. 계좌 승인: Supabase 대시보드 → `approved_users` 테이블 → 계좌번호 행 추가 (`is_active = true`)

### 2단계: Expo 앱 실행

```bash
npx expo start
```

Expo Go 앱(iOS/Android)을 폰에 설치 후 QR 코드 스캔하여 실행합니다.

### 3단계: 게이트 및 설정

1. 앱 시작 → 계좌번호 입력 (Supabase approved_users에 등록된 계좌만 통과)
2. **설정 탭** → 다음 정보 입력 (expo-secure-store에 암호화 저장):
   - KIS AppKey
   - KIS AppSecret
   - 주문 수량 (기본값 1)
   - 청크 시간(초, 기본 3)
   - 버퍼 크기 (기본 31~51 범위, 홀수)
   - LIVE / PAPER 선택 (기본 LIVE)
3. **[토큰 발급]** 클릭 → 토큰 발급 확인 및 만료 배지 갱신

### 4단계: 조회 및 단타 실행

1. **조회 탭**:
   - **보유 종목**: 보유한 미국 주식 조회
   - **미체결**: 미체결 주문 조회 (우측 [취소] 클릭으로 취소 가능)
   - **순위**: 거래량순위 / 거래량급증 / 가격급등락 / 거래증가율 / 거래회전율 / 매수체결강도 선택 → 행 탭하면 단타 인스턴스에 티커 자동 입력
   - **오늘 거래**: KIS 당일 거래 내역 + 앱 기록 병합

2. **단타 탭 — 수동 카드 모드**:
   - **+ 추가** 점선 카드로 인스턴스 추가 (상한 기본 10개)
   - 인스턴스 카드에 티커·수량 입력 (또는 조회 탭에서 프리필)
   - **[Run]** 클릭 → BUY 변곡점 대기 → 자동 매수 → SELL 변곡점 감지 → 전량 매도 (1사이클)
   - **[Stop]** 클릭하면 어느 단계에서든 중단 (포지션 보유 중이면 전량 매도 후 종료)
   - 상태 배지: IDLE / ENTERED / EXITED로 사이클 진행 상태 표시

3. **단타 탭 — 자동 단타 모드** (`docs/development/2026-07-31_단타-자동관리-plan.md` + `2026-08-01_단타-세션-확장-plan.md`):
   - 상단 세그먼트로 **수동 카드 ↔ 자동 단타** 전환 (동시 실행 불가 — 수동 카드가 돌면 자동 시작이 거부돼요)
   - **설정**: 시작금액·최대금액(USD)·최소 속도(틱/초, 기본 1) → **[자동 단타 시작하기]**
   - 리스트 관리: 거래량·거래증가율·거래회전율·상승률 순위(NAS·당일)를 3분마다 폴링해 "+등락 상위 3종목씩" 12종목을 자동 유지 (중복 티커는 1개만, 사이클 중인 종목은 제거 유예 → 최대 13종목). 상승률 원천만 거래량 1만주 이상 필터(저유동성 종목 배제), 한 순위 조회가 실패해도 나머지 원천으로 리스트를 구성한다
   - 단타 관리: 전 종목 시세 수신 + 순간 틱/초(10초 창) 계산 → **최소 속도 이상인 종목 중** 상위 최대 3종목만 변곡점 감시(자격 0개면 감시 안 함) → 매수 신호 시 1종목만 사이클 진행(진입 직전 속도 재검사·금액÷가격 수량 환산·1주도 못 사면 포기) → 매도 후 감시 복귀
   - **세션**: 시작금액으로 개시, 수익 → 절반(하한 $1), 손실 → 2배(상한 없음). "마지막 사이클 수익 + 투입금액 ≥ 최대금액 + 세션 성과 ≥ 0"을 모두 만족하면 세션을 끝내고 시작금액부터 새 세션. 오늘 성과·세션 수는 미국 장 기준일로 집계
   - **현금 부족 일시정지**: 매수 직전 매수가능금액을 조회해 부족하면 주문 없이 일시정지 — "이어서 재개" 또는 "세션 초기화하고 재개"를 사람이 선택 (자동 재개 없음)
   - 장 마감 자동 처리 없음 — 깨어 있는 시간에만 켜 두고 직접 Stop
   - 재시작 시 계좌에 보유 종목이 있으면 경고 알림(자동 정리는 하지 않음 — 수동 정리)

4. **종목 로고** (`docs/development/2026-08-01_로고-도메인-plan.md`):
   - 앱 시작 시 트레이딩뷰 스크리너에서 미국 전 종목의 로고 아이디를 받아 24시간 캐시 (`lib/logoStore.ts`)
   - 리스트의 원형 아바타에 실제 로고(SVG)가 표시되고, 로고가 없거나 로드에 실패하면 기존 이니셜로 폴백

## KIS 검증 & 리허설

### 스모크 테스트 (배포 전 필수)

```bash
KIS_APP_KEY=<your-app-key> KIS_APP_SECRET=<your-app-secret> npm run smoke
```

**RAW_FIELD_DEBUG 모드 활성화** (필드 순서 검증용):

```bash
RAW_FIELD_DEBUG=true KIS_APP_KEY=... KIS_APP_SECRET=... npm run smoke
```

이 모드는 KIS WebSocket 수신 필드를 원본 그대로 덤프하여, `docs/koreainvestment/README.md`의 공식 문서와 대조할 수 있게 해줍니다.

### 실계좌 리허설

미국 정규장 시간(한국 시간 22:30~05:00, 서머타임)에:

1. **필드맵 검증**: RAW_FIELD_DEBUG=true로 실 시세 수신 후 공식 필드 순서와 대조
2. **1사이클 실행**: 실계좌 최소 수량으로 매수 → 변곡점 감지 → 청산 완료
3. **체크리스트 완료**:
   - 실시간체결가 필드 순서 확인
   - 해외주식 매수/매도 TR_ID 설정 확인
   - 지연 시세 실제 지연폭 측정
   - 웹소켓 포트 정상 동작 확인

## 자동 테스트

```bash
npm test
```

과거 틱 배열 재생으로 96개 시나리오 검증 (BUY/SELL 변곡점 판정, 미체결 취소, 1사이클, Stop 청산 등).

## 무선 업데이트 (OTA)

최초 1회 세팅 (expo 로그인 필요):

```bash
eas init
```

이후 production 채널로 업데이트 배포:

```bash
eas update --branch production
```

Expo Go에서 자동으로 최신 버전을 다운로드받습니다 (앱 재시작 시).
