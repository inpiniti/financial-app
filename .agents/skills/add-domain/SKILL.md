# add-domain 워크플로우

새로운 도메인을 정의하고, 도메인 주도 설계(DDD) 원칙과 기술 스택(React Native/Expo, Zustand, TanStack Query, Supabase 등)에 맞춘 설계 문서를 `docs/domain/{도메인명}/`에 생성합니다.

---

## 1. 핵심 설계 원칙

### A. 도메인 주요 구성 요소
- **엔티티(Entity)**: 고유 식별자(ID)를 가지며, 시간에 따라 상태가 변하는 객체
- **값 객체(Value Object, VO)**: 식별자 없이 속성 값들의 조합으로 정의되며, 불변(Immutable)인 객체
- **애그리게잇(Aggregate)**: 연관 객체들의 묶음이자 데이터 변경 시 일관성을 보장하는 경계 단위 (Root Entity를 통해만 접근)
- **도메인 서비스(Domain Service)**: 특정 엔티티/VO 하나에 귀속시키기 어려운 다중 객체 간 비즈니스 로직 처리

### B. 도메인 책임의 3원칙
1. **자기 완결성**: 상태를 외부에서 꺼내와 처리하지 않고 객체 스스로 비즈니스 로직을 수행
2. **비즈니스 규칙 보호**: 유효하지 않은 상태 변화를 방어하고 불변식을 검증 (예: 잔고 부족 시 출금 차단, 최소 주문 수량 검증 등)
3. **응집도 유지**: 데이터와 해당 데이터를 조작하는 로직을 하나의 도메인 객체 안에 집중

---

## 2. 워크플로우 실행 절차

### 단계 1: 도메인 분석 및 범위 정의
1. 사용자로부터 전달받은 도메인명과 요구사항을 파악합니다.
2. 식별할 대상:
   - 고유 식별자가 필요한 핵심 엔티티
   - 불변 속성 값 객체(VO)
   - 트랜잭션/일관성 경계(애그리게잇)
   - 도메인 규칙 및 유효성 검증 로직
   - 관련 데이터 소스, API, UI 화면

### 단계 2: 문서 저장 디렉토리 준비
- 경로: `docs/domain/{도메인명}/` (예: `docs/domain/계좌/`, `docs/domain/주문/`)
- 필요한 문서 파일들을 해당 폴더 아래 마크다운(`.md`) 파일로 생성합니다.

### 단계 3: 표준 도메인 문서 파일 세트 생성
도메인 성격에 맞춰 필요한 파일들을 선별하여 작성합니다. (기본 파일 목록):

| 파일명 | 내용 |
|---|---|
| `README.md` | 도메인 정의, DDD 모델(엔티티/VO/애그리게잇/도메인서비스), 비즈니스 불변식 요약 |
| `feature.md` | 도메인이 제공하는 핵심 비즈니스 기능 및 유스케이스 목록 |
| `architecture.md` | 아키텍처 다이어그램(Mermaid), 데이터 흐름, 컴포넌트 간 상호작용 |
| `schema.md` | 데이터베이스 테이블 구조, 엔티티 필드 명세, 관계도 |
| `source-data.md` | 데이터 원천(KIS API, Supabase, 웹소켓 등 원천 데이터 스펙) |
| `api.md` | 백엔드/외부 연동 엔드포인트, 요청/응답 규격, 에러 코드 |
| `query.md` | 데이터 조회/필터링 조건, 캐싱 키 전략, 실시간 스트림 구독 전략 |
| `client-state.md` | 서버 동기화 상태 관리 (TanStack Query 캐시, 갱신 주기, 무효화 전략) |
| `server-state.md` | 클라이언트 로컬 글로벌 상태 관리 (Zustand 스토어, 액션, 파생 상태) |
| `custom-hook.md` | 도메인 로직 및 상태 캡슐화 훅 (`useDomain...`) 인터페이스 설계 |
| `screens.md` | 관련 화면 경로, 라우팅 URL(Expo Router), 화면 내 진입점 |

> *참고: 필요에 따라 특정 성격이 적은 도메인은 일부 문서를 통합하거나 불필요한 파일을 생략할 수 있습니다.*

### 단계 4: `docs/domain/README.md` 도메인 지도 업데이트
새로 생성된 도메인을 `docs/domain/README.md`의 도메인 목록 표에 등록합니다:
- 도메인 이름 (링크 포함)
- 상태 (현행 / 실험 / 계획 등)
- 관련 코드 경로
- 한 줄 요약

### 단계 5: 사용자에게 생성 결과 안내
생성된 파일 목록과 도메인 모델(Entity, VO, Aggregate, 불변식)의 요약본을 사용자에게 공유합니다.
